# 05. 資金計画と単位経済性

すべての数値は**仮置きの前提**です。[財務モデル_越境EC.xlsx](財務モデル_越境EC.xlsx) の「前提」シートを自分の商材で書き換えると、以下の計算が全て連動します。

前提レート: **1 USD = 150 JPY**

## 1. SKU単位の損益（Unit Economics）

越境EC事業の生死は、**1個売ったときにいくら残るか**で決まります。ここが黒字でない事業は、いくら売上を伸ばしても赤字が拡大するだけです。

### 標準ケース: Amazon US、販売価格 $120 の商品

| 項目 | 金額（USD） | 売価比 | 備考 |
| --- | --- | --- | --- |
| **売上** | **$120.00** | 100.0% | |
| 仕入原価（税抜） | -$40.00 | 33.3% | ¥6,000。**ここが最重要の変数** |
| 販売手数料（Amazon 15%） | -$18.00 | 15.0% | eBayは約13〜15% |
| 出荷手数料（FBA） | -$6.50 | 5.4% | 直送の場合は国際送料に置き換え |
| 広告費（TACoS 12%） | -$14.40 | 12.0% | 立ち上げ期は15〜20%になる |
| 国際送料・通関費の按分 | -$9.00 | 7.5% | まとめて輸入すると下がる |
| **関税（DDP、実効税率10%）** | **-$12.00** | 10.0% | **2026年のde minimis廃止で新たに発生** |
| 決済・為替コスト | -$1.80 | 1.5% | 外貨受取手段で変わる |
| 返品・損失引当 | -$4.80 | 4.0% | カテゴリにより2〜8% |
| **貢献利益（税還付前）** | **$13.50** | **11.3%** | |
| 消費税還付（仕入税額の戻り） | +$4.00 | 3.3% | ¥600。輸出免税による |
| **実質貢献利益** | **$17.50** | **14.6%** | **これが事業の実力値** |

### この表から読むべきこと

**① 仕入原価率が生命線です。**
原価率33% → 実質貢献利益14.6%。これが原価率40%になると、**8.6%まで落ちます**。売価の7%の原価差が、利益をほぼ半減させます。**「安く仕入れる能力」が越境ECにおける唯一かつ最大の競争優位**である理由がこれです。

**② 関税は2026年から効いてくる新コストです。**
de minimis廃止前は、$800以下の直送に関税はかかりませんでした。この $12 は丸ごと2026年に追加された原価であり、**貢献利益とほぼ同額**です。つまり制度変更ひとつで利益が消える構造にあります。**過去の越境EC成功事例の数字をそのまま信じないでください。**

**③ 消費税還付は「おまけ」ではなく利益の4分の1です。**
$17.50 のうち $4.00、つまり**実質貢献利益の約23%が消費税還付**です。課税事業者選択届出書を出し忘れたり、輸出証明の保存を怠ったりすると、これが消えます。→ [03_法務・税務・規制チェックリスト.md](03_法務・税務・規制チェックリスト.md)

### 成立条件のライン

| 指標 | 最低ライン | 目標 |
| --- | --- | --- |
| 販売価格 | **$80以上**（これ未満は固定コスト比率で成立しにくい） | $120〜300 |
| 仕入原価率 | 38%以下 | **33%以下** |
| 実質貢献利益率 | **12%以上** | 18%以上 |
| 実質貢献利益額 | **$12/件以上**（1件あたりの処理工数を回収できる水準） | $25以上 |

| 古物商許可申請 | 2万円 | 19,000円 + 書類取得費 |
| 印鑑・登記事項証明書等 | 2万円 | |
| **初期仕入れ** | **200万円** | 20〜30SKU分。**ここに最大配分する** |
| 撮影機材・梱包資材・PC | 30万円 | 撮影ブース、照明、資材3サイズ分 |
| 保険（PL保険・年払） | 5万円 | |
| 会計ソフト・ツール初期 | 5万円 | |
| **小計** | **250万円** | |
| **運転資金バッファ（3ヶ月分）** | **150万円** | 固定費 + 追加仕入れ |
| **合計** | **400万円** | 推奨レンジ 300〜500万円 |

**仕入れに200万円を割く判断について。**
初期費用の半分を在庫に入れることに抵抗があるかもしれませんが、Phase 0の目的は「何が売れるか」の学習であり、**学習量は試したSKU数に比例します**。SKU数を絞って安全に見えるようにすると、当たりを引く確率が下がり、結果として資金が減るだけで何も分からないまま終わります。ただし**1SKUあたりの投資額は上限を決める**（例: 1SKU 10万円まで）ことで、外したときの損失を限定します。

## 3. 月次固定費

| 項目 | 月額 |
| --- | --- |
| 役員報酬 | 30万円 |
| 倉庫・保管（自宅併用なら按分） | 5万円 |
| 税理士顧問料 | 3万円 |
| ツール・通信 | 2万円 |
| 保険・雑費 | 2.5万円 |
| **合計** | **42.5万円** |

### 損益分岐点

```
必要月商 = 月次固定費 ÷ 実質貢献利益率

現状の実力値（14.6%）: 42.5万円 ÷ 14.6% ≈ 290万円/月
改善後の目標値（18%）: 42.5万円 ÷ 18%   ≈ 236万円/月
```

**月商290万円が黒字化ライン**（改善が進めば236万円まで下がる）。平均単価 $120（¥18,000）なら**月161件**、営業日22日なら1日7〜8件の出荷です。これは1人で回せる水準です（工数38分/件 × 161件 ＝ 月102時間。工数を25分/件まで下げれば月67時間）。

つまり、**この事業は「1人で月商290万円を超えられるか」という問いに帰着します。** 現実的な目標です。

なお、下の24ヶ月計画では貢献利益率が月を追って14%→18%に改善する前提を置いています。これは**仕入先の開拓による原価率の低下と、広告効率の改善**を織り込んだものです。この改善が起きなければ黒字化は後ろにずれます。**貢献利益率の改善こそが、Phase 1で追うべき唯一の経営課題**です。

| M3 | 60 | 10% | 6.0 | 42.5 | -36.5 |
| M4 | 100 | 12% | 12.0 | 42.5 | -30.5 |
| M5 | 140 | 13% | 18.2 | 42.5 | -24.3 |
| M6 | 180 | 14% | 25.2 | 42.5 | -17.3 |
| M7 | 230 | 15% | 34.5 | 42.5 | -8.0 |
| M8 | 280 | 16% | 44.8 | 45 | -0.2 |
| M9 | 330 | 16% | 52.8 | 45 | **+7.8** ← 黒字転換 |

| Y2計 | 11,750 | 20.4%平均 | 2,393 | 1,110 | **+1,283** |

**1年目は約110万円の営業赤字、2年目に黒字化。** これは越境EC事業として健全なカーブです。初期資金400万円で1年目の赤字110万円を吸収でき、残りが在庫に回っている状態になります。

**ただしこの計画の最大の前提は「貢献利益率が14%→18%に改善すること」です。** 改善しなければ黒字化はM12以降にずれ、資金が持たなくなります。売上の伸びより、**貢献利益率の改善を先に確認**してください。

### 資金繰りで注意すべき点

**利益が出ていても現金がない状態が起きます。** 理由は2つ。

1. **在庫の先行投資** — 成長期は売上増加分より在庫増加分の方が大きくなる。月商が倍になるなら在庫も倍必要
2. **入金サイクル** — Amazonは約2週間ごと、eBayも数日〜のラグ。仕入れは先払い

**現金循環日数（CCC）を毎月見てください。**
```
CCC = 在庫日数 + 売掛日数 − 買掛日数
```
在庫60日 + 入金14日 − 買掛0日（現金仕入れ） = **74日**。
月商550万円のとき、運転資金として約 550万 × (74/30) × 原価率33% ≒ **450万円**が在庫と売掛に沈みます。**成長するほど現金が足りなくなる**ので、月商が倍になる前に資金手当てを考えます（日本政策金融公庫の創業融資、信用保証協会付き融資）。

## 5. 資金調達の考え方

| 手段 | 金額 | タイミング | 備考 |
| --- | --- | --- | --- |
| 自己資金 | 300〜500万円 | 創業時 | 必須 |
| **日本政策金融公庫 新規開業資金** | 500〜1,000万円 | **創業時 or 6ヶ月後** | **自己資金と事業計画があれば現実的。金利も低い。最優先で検討** |
| 信用保証協会付き制度融資 | 500万円〜 | 1年目後半 | 決算1期が終わってから通りやすい |
| 商工中金・地銀 | 1,000万円〜 | 2年目以降 | 実績が要る |
| エクイティ（VC等） | — | — | **この事業モデルでは不要**。急成長を求められる資本と相性が悪い |

**推奨: 創業融資を早期に取りにいく。** 越境ECは在庫が現金を食う事業なので、**利益が出てから借りようとすると手遅れ**になります。金利数%を払ってでも在庫を厚くできる方が、機会損失より安いことが多いです。ただし、Phase 0で商材の勝ち筋が見えていない段階で大きく借りるのは危険です。**Phase 0の3ヶ月を自己資金で回し、勝ち筋が見えた時点で融資を申し込む**のが最も安全で、かつ融資審査上も有利です（実績を示せるため）。

## 6. 感度分析 — どの変数が一番効くか

販売価格 $120、ベースの実質貢献利益率 **14.6%** のときに、各変数を動かした場合の影響です。

| 変数 | 悪化ケース | 改善ケース |
| --- | --- | --- |
| **仕入原価率**（33.3% → 38.3% / 28.3%） | **10.1%**（-4.5pt） | **19.1%**（+4.5pt） |
| **広告費率**（12% → 17% / 7%） | **9.6%**（-5.0pt） | **19.6%**（+5.0pt） |
| 関税率（10% → 15% / 5%） | 9.6%（-5.0pt） | 19.6%（+5.0pt） |
| 返品率（4% → 9% / 2%） | 9.6%（-5.0pt） | 16.6%（+2.0pt） |
| 為替（150 → 135円/$ 円高 / 165円 円安） | **11.3%**（-3.3pt） | 17.3%（+2.7pt） |

**結論。**
- 効く順は **広告費率 ≒ 関税率 > 仕入原価率 > 為替 > 返品率**
- ただし**関税率は制御できません**。制御できるのは**広告費率と仕入原価率**です。ここに経営資源を集中してください
- 仕入原価率の影響が広告費率よりわずかに小さいのは、原価が上がると消費税還付も比例して増えるためです。それでも**原価率は継続的に効き続ける変数**であり、仕入先開拓の価値は変わりません
- 為替も制御できません。**円高に振れても成立する原価率（33%以下）で商材を選ぶ**のが、為替に対する唯一の防御です

## まず結論（CEOサマリー）

### 1. 何をやるか

**日本国内で仕入れた商材を、海外の消費者に直接販売する「輸出型越境EC」。**
マーケットプレイス（eBay・Amazon US）で商材を検証し、勝ち筋が見えたら現地在庫化して自社ECへ広げる。

### 2. 2026年に最も効く前提条件（ここが計画の分岐点）

小口・少額・日本から直送というこれまでの越境ECの定番モデルは、**2026年に構造的に不利になりました。**

| 変化 | 内容 | 事業への影響 |
| --- | --- | --- |
| 米国 de minimis 停止 | $800以下の免税が2026年6月24日から無期限停止。全ての商用貨物が正式・簡易通関と関税支払いの対象 | 単価$20〜50の薄利商材は成立しない。通関手数料が1件ずつ乗る |
| EU €150免税の廃止 | 2026年7月1日から €150以下にも1個あたり €3 の暫定関税。2028年に通常税率へ移行予定 | 少額品の相対的なコスト増。EUはVAT(IOSS)登録も必須 |
| 円安の継続 | 日本仕入れの海外価格競争力は依然として高い | 追い風。ただし仕入れ原価率の管理が生命線 |

**この3点から導かれる戦略は明確です。**

- 客単価を上げる（**1注文 $100以上**を狙う。少額多数は通関コストで死ぬ）
- 関税は**DDP（元払い）**に統一する（着荷時に顧客へ請求すると受取拒否と低評価が激増する）
- 検証が済んだ商材は**まとめて現地在庫**に置く（1件ずつの通関コストを在庫単位に分散する）

### 3. 推奨する進み方（3フェーズ）

| フェーズ | 期間 | やること | 撤退・継続の判定 |
| --- | --- | --- | --- |
| **Phase 0 検証** | 0〜3ヶ月 | eBay + Amazon US。買い切り少量。日本から直送DDP。20〜30SKUを試す | 累計売上150万円 / 実質貢献利益率12%以上のSKUが3つ以上出るか |
| **Phase 1 集中** | 4〜9ヶ月 | 勝ちSKUをFBA・現地3PLへ先出し在庫。SKUを絞って深く積む | 月次の貢献利益が固定費を上回るか |
| **Phase 2 資産化** | 10〜18ヶ月 | Shopifyで自社EC。リピート・LTV・ブランド化。EU/アジアへ展開 | 自社EC比率20%以上 / CAC回収12ヶ月以内 |

**フェーズを飛ばさないこと。** 最初から自社ECとブランドを作ろうとして失敗する越境EC事業者が最も多いパターンです。集客ゼロから始まる自社ECより、既に買う気の客がいるモールで「何が売れるか」を先に確定させる方が、同じ資金で何倍も学習できます。

### 4. 初期に必要な意思決定と資金

| 項目 | Lean版（初年度） | フル版（実証後） |
| --- | --- | --- |
| 事業形態 | **個人事業主**（開業届のみ・0円） | 合同会社（設立6万円）→ 月商1,000万円で株式会社化 |
| 消費税 | **課税事業者選択届出書を開業年の12月31日までに提出** | 設立事業年度中に提出 |
| 初期資金 | **60万円**（うち仕入れ40万円） | 300〜500万円（うち仕入れ150〜250万円） |
| 働き方 | **兼業**（専業にすると損益分岐が10倍） | 専業 |
| 許認可 | 中古品を扱うなら**古物商許可**（必須・約40日） | 同左 |

**消費税の届出は、個人事業主でも法人でも同じくらい重要です。** 輸出免税による還付は実質貢献利益の約23%を占めます。出し忘れると利益の4分の1が消えるので、**ここだけは税理士にスポット相談してください**（1〜3万円）。

### 5. 最初の1週間でやること（Lean版）

1. 扱う商材ドメインを1つ決める（→ [01_事業戦略.md](01_事業戦略.md) の選定スコアで）
2. 古物商許可を申請する（**40日かかるので最初にやる**。中古を扱う可能性があるなら申請しておく）
3. 開業届・青色申告承認申請書を税務署に出す（**0円**）
4. 税理士に1回スポット相談する（消費税課税事業者選択の可否とタイミング）
5. eBayの出品アカウントを開設する（本人確認に数日）

詳細な週次計画は [09_Lean版_初年度実証計画.md](09_Lean版_初年度実証計画.md) と [06_90日ローンチ計画.md](06_90日ローンチ計画.md) にあります。

## この資料の使い方と注意

- 数値はすべて**仮置きの前提値**です。[財務モデル_越境EC.xlsx](財務モデル_越境EC.xlsx) の「前提」シートを自分の商材で書き換えると、全ての損益が連動します。
- 税務・法務の記述は2026年8月時点の公開情報にもとづく**整理**であり、税務判断そのものではありません。特に消費税還付の要件、輸出証明の保存方法、現地VAT登録は、**必ず税理士・通関業者に確認**してください。輸出証明の不備による還付否認は越境ECで最も多い税務トラブルです。
- 制度変更が激しい領域です。特に米国の関税と de minimis、EUの customs reform は数ヶ月単位で動きます。[08_リスク登録簿.md](08_リスク登録簿.md) の再確認サイクルに従って更新してください。

# 07. KPIとガバナンス

## 1. 北極星指標

### **月次 実質貢献利益（Contribution Profit）**

売上でも粗利でもなく、**「その月に売った商品から、変動費を全部引いて、消費税還付を足した後に残った金額」**を唯一の中心指標にします。

```
実質貢献利益 = 売上
             − 仕入原価 − 販売手数料 − 出荷手数料 − 広告費
             − 国際送料 − 関税 − 決済/為替 − 返品損失
             + 消費税還付相当額
```

**なぜ売上でないのか。** 越境ECは売上を伸ばすこと自体は簡単です。値下げして広告を打てば、いくらでも売れます。しかしそれは現金を燃やしているだけです。**貢献利益がプラスでない売上には価値がありません。**

**なぜ営業利益でないのか。** Phase 0〜1では固定費が売上に対して大きすぎ、営業利益は「まだ小さい」という情報しか返しません。貢献利益なら、**1商品ずつの意思決定に直接使えます**。

## 2. 階層別のKPI

### 経営レベル（月次で見る）

| 指標 | 定義 | 目標 |
| --- | --- | --- |
| **月次実質貢献利益** | 上式 | 固定費（月42.5万円）を上回る（Phase 1で達成） |
| 実質貢献利益率 | 貢献利益 ÷ 売上 | 初期14% → **18%以上へ改善** |
| 月次バーン | 営業CFのマイナス額 | 縮小し続けること |
| **ランウェイ** | 現預金 ÷ 月次バーン | **6ヶ月以上を常に維持** |
| 現金循環日数（CCC） | 在庫日数 + 売掛日数 − 買掛日数 | 90日以下 |

### 商材レベル（週次で見る） — 最も重要

| 指標 | 定義 | 判定 |
| --- | --- | --- |
| **SKU別 実質貢献利益率** | SKU単位で計算 | **12%未満は撤退候補** |
| **SKU別 実質貢献利益額** | 円/件 | **$12（¥1,800）未満は工数を回収できない** |
| Sell-through率 | 60日以内に売れた比率 | 70%以上 |
| 在庫滞留日数 | 仕入から販売までの日数 | 中央値60日以下 |
| **90日超滞留在庫比率** | 滞留額 ÷ 総在庫額 | **20%を超えたら値下げして現金化** |
| 在庫回転率 | 年間売上原価 ÷ 平均在庫 | 6回/年以上 |

### チャネルレベル（週次で見る）

| 指標 | 目標 |
| --- | --- |
| TACoS（広告費 ÷ 売上） | **15%以下** |
| 転換率（Amazon） | 10%以上 |
| Sell-through（eBay） | 出品数に対する月間販売率 20%以上 |
| **セラー評価** | **98%以上** |
| Order Defect Rate（Amazon） | **1%未満**（超えるとアカウント停止リスク） |
| Late Shipment Rate | **4%未満** |
| 返品率 | 5%以下 |
| 初回返信時間 | **24時間以内** |

### オペレーションレベル（月次で見る）

| 指標 | 目標 |
| --- | --- |
| 1件あたり処理工数 | 38分 → **25分** → 15分 |
| 1人あたり月間出荷件数 | 150件以上 |
| **輸出証憑の完備率** | **100%**（1件でも欠けたら還付リスク） |
| 出荷ミス率（誤配送・欠品） | 0.5%以下 |

## 3. アカウント健全性 — 事業の生命線

**モールのアカウントが停止すると、翌日から売上がゼロになります。** これは越境ECにおける最大の単一障害点です。以下は他の全てのKPIに優先します。

| 監視項目 | 閾値 | 超えたときのアクション |
| --- | --- | --- |
| Order Defect Rate（Amazon） | 1% | **即座に出品を減らして品質改善に集中** |
| Late Shipment Rate | 4% | 発送リードタイムの表示を伸ばす |
| 知財侵害の申立 | **1件でも** | **24時間以内に仕入証憑を添えて反論** |
| ポリシー違反の警告 | **1件でも** | 該当出品を即取り下げ、原因を潰す |
| eBay Seller Level | Above Standard 未満 | 手数料が上がる。取引品質を最優先に戻す |

**構造的な対策: 単一チャネル依存を避ける。**
売上の70%以上が1チャネルに集中したら、それはリスクです。Phase 1でチャネルを2つ以上、Phase 2で自社ECを持つのは、成長のためだけでなく**生存のため**です。

## 4. 経営会議の型

### 週次レビュー（毎週月曜・30分）

**見るもの（それ以外は見ない）:**
1. 先週の売上・出荷件数・貢献利益
2. **SKU別の売れ行き上位5 / 下位5**
3. 滞留在庫（60日超）のリスト
4. アカウント健全性指標（赤信号があるか）
5. 未対応の顧客問い合わせ

**決めること:** 今週の仕入れ / 値下げするSKU / 追加出品するSKU

### 月次レビュー（月初・90分）

1. 月次PLと貢献利益（実績 vs 計画）
2. **SKU別の実質貢献利益を全件計算** → 撤退候補の決定
3. 資金繰り（ランウェイ、CCC、翌月の仕入予算）
4. 輸出証憑の完備率チェック（税理士と）
5. KPIのうち目標未達のものについて、原因と打ち手

### 四半期レビュー（90分）

1. Phase判定（次のフェーズへ進むか、留まるか、戻るか）
2. 商材ポートフォリオの見直し
3. 制度環境の再確認（**関税・de minimis・VAT・為替**）
4. 資金調達の要否
5. 撤退基準への抵触チェック

## 5. 撤退基準（先に決めておく）

**事業をやめる基準を、始める前に文字にしておいてください。** 走り出してからでは、必ず判断が甘くなります。

| タイミング | 基準 | アクション |
| --- | --- | --- |
| **3ヶ月** | 貢献利益率12%以上のSKUが3つ未満 | 商材ドメインを変更（撤退ではない） |
| **6ヶ月** | 2回目のドメイン変更後も月商100万円未満 | **事業モデルの根本的な見直し。継続の是非を判断** |
| **12ヶ月** | 月次貢献利益が固定費を一度も上回っていない | **撤退を第一選択とする。** 在庫を現金化して損失を確定 |
| **随時** | ランウェイが3ヶ月を切った | 追加資金を確保できないなら、在庫を投げ売りして撤退 |
| **随時** | 主要チャネルのアカウントが恒久停止 | 代替チャネルの立ち上げ可否を1ヶ月で判断 |

**撤退は失敗ではありません。** 越境ECは在庫を持つ事業なので、**判断を遅らせるほど回収できる現金が減ります**。「あと3ヶ月」を3回繰り返して在庫の山と借入だけが残るのが、この業種で最も多い終わり方です。基準に触れたら、感情を挟まず実行してください。

## 6. 記録すべきデータ（最初から）

以下を1行1レコードで貯めることが、**3ヶ月後の意思決定の質を決めます**。

### 仕入台帳
`仕入日 / 仕入先 / SKU / 品名 / 数量 / 仕入単価(税抜) / 消費税額 / 適格請求書の有無 / 保管場所`

### 販売台帳
`注文ID / 販売日 / チャネル / SKU / 売価 / 手数料 / 広告費 / 仕向国 / 発送方法 / 送料 / 関税 / 発送日 / 伝票番号 / 証憑リンク / 返品有無`

### SKU台帳
`SKU / カテゴリ / 仕入日 / 原価 / 出品日 / 販売日 / 滞留日数 / 実質貢献利益 / 貢献利益率 / 再仕入の可否`

**このうち「証憑リンク」の列を絶対に空にしないでください。** 消費税還付の可否がここで決まります。→ [03_法務・税務・規制チェックリスト.md](03_法務・税務・規制チェックリスト.md)

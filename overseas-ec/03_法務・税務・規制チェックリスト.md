# 03. 法務・税務・規制チェックリスト

> ⚠️ **この文書は2026年8月時点の公開情報にもとづく整理であり、税務・法務の判断ではありません。**
> 特に消費税還付、輸出証明の保存方法、現地VAT登録については、必ず税理士・通関業者・司法書士に確認してください。
> 越境ECで最も多い税務トラブルは「輸出証明が不十分で消費税還付を否認される」ことです。開業初日から証憑の保存ルールを作ってください。

## 1. 会社設立

### 法人形態の選択

| 項目 | 合同会社（LLC） | 株式会社 |
| --- | --- | --- |
| 設立費用 | 約6万円（電子定款） | 約20〜25万円 |
| 決算公告 | 不要 | 必要（年間数万円） |
| 役員任期 | なし | 最長10年（重任登記が必要） |
| 対外的信用 | やや劣る | 高い |
| 外部からの出資 | 受けにくい | 受けやすい |
| **推奨** | **✅ 起点はこちら** | 月商1,000万円到達 or 外部調達検討時に組織変更 |

**推奨: 合同会社。** モールの法人審査も海外の取引先も、合同会社で問題になることはほとんどありません。浮いた15万円は初回の仕入れに回す方が事業として合理的です。

### 資本金

**100〜300万円を推奨。1,000万円未満は必須条件。**

- 資本金1,000万円以上だと、設立初年度から消費税の納税義務者になり、かつ住民税均等割が上がります
- ただし本事業は**消費税課税事業者を自ら選択する**ため（後述の還付のため）、消費税面のメリットは実質ありません。均等割と対外的な見え方のバランスで決めます
- 資本金が薄すぎると（1円など）モールの審査や決済会社の審査で不利になることがあります

### 事業目的（定款）に入れておくべき文言

設立後に追加すると変更登記費用（3万円）がかかるので、最初から入れておきます。

- インターネットを利用した各種商品の販売業
- 商品の輸出入及び販売業
- **古物営業法に基づく古物商** ← 中古を扱う可能性があるなら必須
- 通信販売業
- 前各号に附帯関連する一切の業務

## 2. 許認可

| 許認可 | 必要になる条件 | 窓口 | 費用 | 期間 |
| --- | --- | --- | --- | --- |
| **古物商許可** | **中古品を仕入れて販売する場合（海外向けでも必要）** | 所轄警察署（生活安全課） | 19,000円 | **約40日** |
| 酒類輸出卸売業免許 | 酒類を輸出する場合 | 所轄税務署 | 登録免許税 | 2〜4ヶ月 |
| 医薬品等輸出届 | 医薬品・医薬部外品・化粧品・医療機器を輸出する場合 | 都道府県薬務課 | — | 都度 |
| 食品関連 | 相手国の規制に従う（日本側の許可は原則不要だが、輸出証明書が必要な国あり） | 農林水産省・厚労省 | — | 品目による |

**古物商許可は最優先で申請してください。** 40日かかるため、これがボトルネックになります。「中古を扱うかまだ決めていない」段階でも、可能性があるなら先に出しておくのが正解です。

> **よくある誤解**: 「海外に売るだけだから古物商は不要」は誤りです。古物営業法は**国内での古物の売買・交換**を規制するもので、国内で中古品を買い取る・仕入れる時点で許可が必要になります。

## 3. 輸出規制（輸出貿易管理令の該非判定）

一般的な消費財はほぼ非該当ですが、以下は**必ず該非判定を取ってください**。

| 品目 | 懸念 |
| --- | --- |
| 高性能カメラ・光学機器・赤外線機器 | リスト規制（軍事転用の可能性） |
| ドローン・無人機 | リスト規制 |
| 暗号機能を持つ機器・ソフトウェア | リスト規制 |
| 高性能な計測機器・工作機械 | リスト規制 |
| 炭素繊維、特殊素材 | リスト規制 |

また、**キャッチオール規制**により、リスト非該当品でも大量破壊兵器等への転用のおそれがある場合は許可が必要です。加えて、**制裁対象国・対象者（北朝鮮、ロシアの一部、イラン等）への輸出は禁止または許可制**です。

**実務対応**: 取引先が新規の国・大口の場合、経済産業省の「外国ユーザーリスト」と仕向地を確認する運用を最初から入れておきます。

## 4. 消費税（ここが利益の源泉）

### 輸出免税と還付の仕組み

```
日本国内での仕入れ      →  消費税10% を支払う（仮払消費税）
海外の消費者への販売    →  輸出免税（消費税0%）
                        ────────────────────────
                        仮払消費税が全額還付される
```

**仕入れ100万円（税込110万円）の商品を輸出すると、10万円が戻ってきます。** これは越境EC事業の貢献利益の1〜2割に相当する規模で、事業の成否を左右します。

### 還付を受けるための必須手続き

| # | 手続き | 期限 | 失敗するとどうなるか |
| --- | --- | --- | --- |
| 1 | **消費税課税事業者選択届出書**の提出 | **設立事業年度の末日まで**（第1期から適用を受ける場合） | **初年度の還付を丸ごと失う。最も多い致命的ミス** |
| 2 | 適格請求書発行事業者の登録（インボイス） | 早期 | 仕入税額控除の要件を満たせない |
| 3 | 輸出証明書類の保存（7年） | 継続 | **還付が否認される** |
| 4 | 仕入れのインボイス（適格請求書）の保存 | 継続 | 仕入税額控除が認められない |

> **設立事業年度が短い場合**（例: 12月設立で3月決算）、届出の期限も短くなります。**設立登記が完了したその週に税理士へ連絡してください。**

### 輸出証明の保存 — 最重要の実務ポイント

輸出免税の適用には、取引区分に応じた証明書類の保存が必要です。

| 発送方法・金額 | 必要な証明 |
| --- | --- |
| **20万円超**（通関を伴う輸出） | **輸出許可通知書**（税関発行）。通関業者から必ず受け取り保管する |
| **20万円以下の郵便物** | 日本郵便の引受を証する書類（差出人控え、EMS/eパケットの発送伝票控え、インボイス控え等）。**発送日・品名・数量・受取人・金額が分かるもの** |
| クーリエ（DHL/FedEx等） | 各社の発行するAWB（Air Waybill）と輸出申告関連書類 |

**運用ルールとして最初に決めること。**
- 出荷1件ごとに「注文ID・発送伝票番号・発送日・金額・仕向地・証憑PDF」を1行で記録する台帳をつくる
- 発送伝票の控えとインボイス控えは、注文IDでファイル名を統一してクラウドに保存する（7年保存）
- 月次で「販売記録の件数」と「輸出証明が揃っている件数」を突合する

否認事例の多くは「売上は輸出だと主張しているが、その1件1件の証憑が出せない」というものです。**件数が少ないうちに仕組みを作らないと、月500件になってから遡って揃えることは不可能です。**

## 5. 現地の税

| 市場 | 制度 | 誰が納めるか | 自社ECの場合 |
| --- | --- | --- | --- |
| **米国** | Sales Tax（州税） | モール経由は **Marketplace Facilitator法**によりAmazon/eBayが代理徴収 | 州ごとの economic nexus（一般に年間売上$100,000 または200取引）を超えたら登録・申告義務。**自社ECを始めたら要監視** |
| **米国** | 関税（Duty） | 輸入者。DDPなら販売者負担 | HTSコード分類が必要。2026年は追加関税の変動が大きい |
| **EU** | VAT | €150以下はIOSSで販売者が徴収・申告。モール経由はモールが「みなし供給者」 | **IOSS登録には域外事業者はEU域内の仲介者の指定が必要** |
| **EU** | 関税 | 2026年7月1日から €150以下にも1個 €3 の暫定関税 | DDP前提で価格設計する |
| **英国** | VAT | £135以下は販売者が英国VAT登録して徴収 | 自社EC販売なら登録必須 |
| **法人税（PE）** | — | 現地に「恒久的施設」があると現地法人税の対象 | 通常、**保管のみの倉庫（FBA含む）は準備的・補助的活動としてPEに該当しない**とされるが、国によって扱いが異なるため要確認 |

## 6. 知的財産と真贋

**アカウント停止の最大の原因は知財クレームです。** ここを甘く見ると、月商が立ち始めた瞬間に事業が止まります。

| リスク | 内容 | 対策 |
| --- | --- | --- |
| **商標権侵害の申立** | 権利者が「正規流通ではない」としてモールに申し立てる | 一次卸・正規代理店からの仕入れ、**仕入インボイスの保管**（真贋証明として提出できる形で） |
| **並行輸入の争い** | 権利者が国別に流通をコントロールしている場合 | 事前にメーカーの海外販売ポリシーを確認。契約で越境販売が禁じられている商材を避ける |
| **模倣品の混入** | 仕入れ先で偽物を掴む | 相場より安すぎるロットを買わない。仕入先を分散しない（信頼できる少数に絞る） |
| **著作権（画像）** | メーカー画像の無断使用 | **自社撮影を原則にする**。工数はかかるが、これが後で効く |
| **意匠・特許** | 特に自社ブランド展開時 | Phase 2で商標出願（米国USPTO、EUIPO）を検討 |

**実務ルール。**
- 全ての仕入れについて、**日付・仕入先・品名・数量・金額が記載された書類（適格請求書）を必ず取得**する。フリマアプリの個人からの仕入れは真贋証明が出せないため、事業の主軸にしない
- モールから申立てが来たら、**24時間以内に仕入証憑を添えて反論する**。放置すると自動的にストライクが積まれる

## 7. その他の必須対応

| 項目 | 内容 |
| --- | --- |
| **特定商取引法の表示** | 自社EC（Shopify等）を持つ場合、事業者名・住所・連絡先・返品条件の表示義務。海外向けサイトでも日本法人である以上、対応する |
| **個人情報・GDPR** | EU居住者の個人データを扱うならGDPR対応（プライバシーポリシー、データ処理の根拠、削除請求への対応）。Shopifyのアプリで一定程度対応できる |
| **PL保険（生産物賠償責任保険）** | 米国は訴訟リスクが高い。**海外PL保険は必ず入る**。年数万円〜。Amazonは一定売上以上で加入を義務付けている |
| **貿易保険・貨物保険** | 高額品を送る場合、クーリエの補償上限を超える分は個別に付保 |
| **銀行口座・決済** | 法人口座（ネット銀行推奨）、外貨受取（Wise Business、Payoneer等）。**モールの入金は外貨なので、為替手数料の低い受取手段が利益に直結する** |

## 8. 設立から営業開始までのチェックリスト

- [ ] 事業ドメインと商材カテゴリを決定
- [ ] 商号・本店所在地・事業目的を確定（古物商の文言を含める）
- [ ] 司法書士に合同会社設立を依頼（1〜2週間）
- [ ] **古物商許可を申請（約40日。最優先）**
- [ ] 法人口座を開設（2〜4週間かかることがある）
- [ ] 税務署へ法人設立届出書・青色申告承認申請書を提出
- [ ] **消費税課税事業者選択届出書を提出（設立事業年度末まで）** ← 最重要
- [ ] 適格請求書発行事業者の登録申請
- [ ] 会計ソフトを導入し、輸出証憑の保存ルールを設定
- [ ] eBay / Amazon北米のセラーアカウントを開設
- [ ] 外貨受取手段（Wise Business等）を用意
- [ ] 海外PL保険に加入
- [ ] 通関業者・クーリエ（DHL/FedEx）と法人契約の相談
- [ ] 扱う商材の輸出該非判定を実施

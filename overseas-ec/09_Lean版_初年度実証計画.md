# 09. Lean版 — 初年度は実証に徹する

**この文書は [05_資金計画と単位経済性.md](05_資金計画と単位経済性.md) の「初期投資400万円・法人設立」プランに代わる、初期投資を最小化した実証プランです。**

初年度の目的を「事業を成長させること」ではなく、**「この事業が自分にとって成立するかを、最小の金銭的損失で確かめること」**に置き換えます。

---

## 1. 結論

| 項目 | フル版（05） | **Lean版（本書）** |
| --- | --- | --- |
| 初期投資 | 400万円 | **60万円** |
| 事業形態 | 合同会社 | **個人事業主** |
| 月次固定費 | 42.5万円 | **2万円** |
| 損益分岐 月商 | 290万円 | **14万円** |
| 損益分岐 出荷件数 | 月161件 | **月8件** |
| 1年目の目標 | 月商550万円 | **月商120万円 / 勝ち筋の特定** |
| 失敗したときの損失 | 300万円超 | **約36万円**（在庫を6割で処分した場合） |

**Lean版の本質は「損益分岐点を月商14万円まで下げること」です。** 月8件売れれば赤字にならない状態を作れば、焦って判断を誤る理由がなくなります。越境ECで最も高くつくのは、**固定費に追われて売れない商材を値下げし続けること**です。

## 2. 最大のコスト削減：法人設立を後ろ倒しにする

### 個人事業主で始める

| 項目 | 法人（合同会社） | **個人事業主** |
| --- | --- | --- |
| 開業費用 | 6万円〜 | **0円**（開業届のみ） |
| 住民税均等割 | **年7万円（赤字でもかかる）** | 0円 |
| 社会保険 | **強制加入。役員報酬に応じて負担** | 国保・国民年金のまま |
| 税理士 | 顧問契約が実質必須（月3万円） | **決算のみスポット（年10〜15万円）** |
| **消費税の輸出還付** | **受けられる** | **受けられる（重要）** |
| eBay / Amazon | 出品可 | **出品可** |
| 対外信用・融資 | 有利 | 不利 |
| 責任 | 有限責任 | 無限責任 |

**年間で約50〜80万円の差**が出ます。実証段階でこれを払う理由はありません。

### ⚠️ 個人事業主でも消費税還付は受けられます — ただし届出が必要

これがLean版で最も重要な論点です。**「法人にしないと還付を受けられない」というのは誤解**です。個人事業主でも、課税事業者を選択すれば輸出免税による還付を受けられます。

| 手続き | 期限 |
| --- | --- |
| 開業届・青色申告承認申請書 | 開業から1〜2ヶ月以内 |
| **消費税課税事業者選択届出書** | 原則は前年12月31日まで。ただし**新規開業した年は、その年の12月31日まで**に提出すれば当年から適用 |
| 適格請求書発行事業者の登録 | 早めに |

**注意点。** 課税事業者を選択すると、原則**2年間は継続適用**されます（途中でやめられない）。輸出中心なら還付が続くので問題ありませんが、**国内販売に軸足を移すと不利になる**可能性があります。この判断は税理士に一度だけスポットで相談してください。**ここは節約する場所ではありません。** 相談料1〜3万円で、還付（貢献利益の23%）を守れます。

### 法人化のタイミング

以下のいずれかに達したら法人化を検討します。

- 年商が1,000万円を超える見込みになった
- 所得（利益）が年500〜800万円を超えた（税率の逆転点）
- 融資を受けたい、取引先が法人を求める
- 在庫リスクが大きくなり、有限責任にしたい

## 3. Lean版 初期費用（60万円）

| 項目 | 金額 | 備考 |
| --- | --- | --- |
| 開業届・青色申告承認申請 | **0円** | 税務署に出すだけ |
| 古物商許可 | 2万円 | **中古を扱うなら必須。40日かかるので最初に出す** |
| **初期仕入れ** | **40万円** | **10〜15SKU。1SKUあたり2〜4万円** |
| 撮影・梱包資材 | 5万円 | 背景紙・LED照明・資材。カメラはスマホで十分 |
| PL保険（年払） | 3万円 | **削らない**（後述） |
| 会計ソフト（年額） | 1.2万円 | freee/マネーフォワードの個人向け |
| 予備費 | 8.8万円 | |
| **合計** | **60万円** | |

### 初期投資を抑える「正しいやり方」

**❌ 間違い：SKU数を減らす**
「10SKUを5SKUにすれば半分で済む」——これは最悪の節約です。**Phase 0の目的は学習であり、学習量は試したSKU数に比例します。** SKUを減らすと、当たりを引く確率が下がるだけで、資金は同じように減ります。

**✅ 正しい：1SKUあたりの金額を下げる**
1SKU 10万円 × 20SKU（200万円）を、**1SKU 3万円 × 13SKU（40万円）**にします。SKU数はできるだけ維持し、単価の低い商材や仕入れ数量を絞ります。

**✅ 正しい：回転させる**
40万円を1回使って終わりではなく、**売れた分を次の仕入れに回して3〜4回転させます**。年間の仕入総額は120〜160万円になりますが、**手元から出す現金は40万円のまま**です。これがLean版の資金効率の核心です。

## 4. Lean版 月次固定費（2万円）

| 項目 | 月額 | 判断 |
| --- | --- | --- |
| 生活費・自分への報酬 | **0円** | **兼業を前提**。生活費は本業から。→ 下の「専業の場合」参照 |
| 倉庫・保管 | **0円** | 自宅の一室 |
| 税理士 | 1.25万円 | 決算スポット年15万円の月割 |
| ツール・通信 | 0.5万円 | 会計ソフトのみ。**Amazon大口出品（月$39.99）は契約しない** |
| 保険 | 0.25万円 | PL保険 年3万円の月割 |
| **合計** | **2万円** | |

```
損益分岐 月商 = 2万円 ÷ 14.6% ≈ 14万円/月
必要出荷件数 = 14万円 ÷ 1.8万円 ≈ 8件/月
必要作業時間 = 8件 × 38分 ≈ 5時間/月
```

**月8件、月5時間で赤字にならない。** これが、兼業しながら実証できる理由です。

### ⚠️ 専業でやる場合は前提が変わります

生活費を事業から取るなら、それが固定費に乗ります。

| 生活費 | 月次固定費 | 損益分岐 月商 | 必要件数 | 必要作業時間 |
| --- | --- | --- | --- | --- |
| 0円（兼業） | 2万円 | **14万円** | 月8件 | 月5時間 |
| 月20万円（専業） | 22万円 | **151万円** | 月84件 | 月53時間 |
| 月30万円（専業） | 32万円 | **219万円** | 月122件 | 月77時間 |

**専業にすると損益分岐が10倍以上になります。** 「初期投資を抑えて実証したい」という方針と専業は相性が悪いので、**実証期間中は兼業を強く推奨します。** 月商が150万円を安定して超えてから専業に切り替えるのが、資金的にも精神的にも安全です。

## 6. 削ってよいコストと、削ってはいけないコスト

### ✅ 削ってよい

| 項目 | 理由 |
| --- | --- |
| 法人設立 | 実証段階で信用は要らない。年50〜80万円の差 |
| 事務所・倉庫 | 自宅で十分。月67件なら在庫は数畳に収まる |
| 自分への報酬 | 兼業で賄う。損益分岐が10倍変わる |
| Amazon大口出品（月$39.99） | 小口でも出品できる。月50件を超えてから切り替える |
| 有料リサーチツール | eBayのTerapeakとKeepa無料版で足りる |
| 在庫管理ツール | スプレッドシートで足りる（100SKUまで） |
| 撮影用カメラ | スマホで十分。照明の方が画質に効く |

### ❌ 削ってはいけない（削ると事業が壊れる）

| 項目 | 削ると何が起きるか |
| --- | --- |
| **クーリエ配送とDDP** | **最重要。** 郵便で安く送ると、2026年のde minimis廃止で顧客が着荷時に関税を請求される。受取拒否・低評価・返金が連鎖し、アカウント健全性が壊れる。**送料を数百円削って評価を落とすのが、この事業で最も高くつく間違いです** |
| **消費税の届出と税理士へのスポット相談** | 還付は実質貢献利益の23%。相談料1〜3万円をケチって届出を落とすと、桁違いに損をする |
| **PL保険** | 米国は訴訟リスクが高い。年3万円で数百万円のリスクを移転できる |
| **撮影の質** | 傷を隠すと返品とクレーム対応の工数で高くつく。**照明だけは買う** |
| **古物商許可** | 無許可営業は古物営業法違反。中古を扱うなら例外なし |
| **仕入証憑の保管** | 知財クレーム時に真贋を証明できず、アカウント停止に直結 |
| **SKU数** | 減らすと学習量が減る。金額を下げて数は維持する |

### ❌ 「安く済ませる方法」に見えて事業を壊すもの

- **無在庫転売（ドロップシッピング）** — 在庫リスクはゼロですが、eBay/Amazonのポリシー違反になりやすく、発送遅延で評価が崩れます。**アカウント停止で全てを失うリスクに対して、得られるものが小さすぎます**
- **フリマアプリからの仕入れを主軸にする** — 適格請求書が出ないため**消費税の仕入税額控除ができず**、還付が減ります。さらに真贋証明も出せません
- **虚偽の少額申告・Gift表記** — 関税ほ脱です。事業ごと終わります

## 7. Lean版の90日 / 365日 判定

### Day 90

| 結果 | 判定 |
| --- | --- |
| 累計売上30万円以上、貢献利益率12%以上のSKUが2つ以上 | ✅ 継続。仕入れを回転させる |
| 売れているが利益率10%未満 | ⚠️ 商材の単価・重量を見直す |
| 売上10万円未満 | ⚠️ 商材ドメインを変更。**追加投資はしない** |

### Day 365

| 結果 | 判定 | 次のアクション |
| --- | --- | --- |
| 月商100万円超 / 累計営業利益がプラス | **✅ 本格化** | 法人化、創業融資、FBA在庫化、専業化を検討 |
| 月商50〜100万円 / 収支トントン | **○ 継続（兼業のまま）** | もう1年、兼業で規模を上げる。**焦って専業化しない** |
| 月商50万円未満 / 累計赤字 | **❌ 撤退** | 在庫を投げ売りして現金化。**損失は約36万円**（在庫を仕入値の6割で処分した場合。処分率次第で30〜50万円） |

**Lean版の最大の価値は、この最後の行にあります。** 失敗したときの損失が数十万円に限定されているので、**撤退の判断を冷静に下せます**。400万円を突っ込んでいると、人は撤退できません。損切りできずに追加投資を重ねるのが、この業種で最も多い終わり方です。

## 8. Lean版で最初にやること（優先順）

1. **商材ドメインを1つ決める**（→ [01_事業戦略.md](01_事業戦略.md) のスコア）
2. **古物商許可を申請する**（中古を扱うなら。40日かかる）
3. **開業届・青色申告承認申請書を出す**（税務署、無料）
4. **税理士に1回だけスポット相談する**（消費税課税事業者選択の可否とタイミング）
5. **消費税課税事業者選択届出書を出す**（開業年の12月31日まで）
6. eBayアカウントを開設する（本人確認に数日）
7. **10〜15SKUを40万円で仕入れる**（1SKUあたり2〜4万円）
8. 撮影環境を作る（照明と背景紙で1万円）
9. DHL/FedExのアカウントを作る（**個人でも法人契約の相談は可能**。まずは通常アカウントでDDP発送）
10. 出荷台帳と証憑保存のルールを決める（→ [07_KPIとガバナンス.md](07_KPIとガバナンス.md)）

## 9. フル版に切り替えるタイミング

Lean版はあくまで実証用の構えです。以下が揃ったら [05_資金計画と単位経済性.md](05_資金計画と単位経済性.md) のフル版へ移行します。

- 月商100万円を3ヶ月連続で超えた
- 実質貢献利益率15%以上のSKUが5つ以上ある
- 自分の作業時間が月80時間を超え、これ以上は物理的に伸ばせない
- 在庫を厚くすれば売上が伸びると、データで確信できる

このタイミングで、**法人化 → 創業融資 → FBA在庫化 → 専業化**を一気に進めます。実績があるので融資も通りやすく、リスクも読めています。**順番を守ることが、この事業で最も効く資金戦略です。**

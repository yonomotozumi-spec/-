# 寝かしつけアニメーション 企画フォルダ

子どもが寝るときに見る、短いアニメーションを作るための企画資料です。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `01_ジャンル案.md` | 寝かしつけアニメの基本ルールと、ジャンル候補6案の比較・おすすめ |
| `02_台本_おつきさまのこぶね.md` | おすすめジャンルの完成台本 v2（約6分40秒、動物8匹、19カット、歌詞つき） |
| `03_制作の進め方.md` | 台本を実際の動画にするまでの手順（プログラミング不要） |
| `04_アニメーションの雰囲気.md` | 子どもが好む見た目・動き・声・音楽の方針と、生成用の共通フレーズ |
| `05_読み上げ用テキスト.md` | ナレーション生成に使う漢字表記の文（ひらがな分かち書きだと片言になるため） |
| `narration/` | 採用したナレーション音声（Haruma の声・漢字表記、カットごと） |
| `images/` | 採用した場面の絵（Kling で生成） |
| `videos/` | Kling で動画化した場面（カット4〜9）と、絵＋ナレーションをつないだ通し見本 |
| `bgm/` | ElevenLabs で作ったオルゴール風BGM（候補A・B、90秒とループ版） |
| `samples/` | 採用したナレーションの声の見本（カット5・ふくろう） |
| `archive/` | 以前の版（v1 台本、Sumiku の声のナレーション v1・v2） |

## 進め方

1. `01_ジャンル案.md` を読んで、ジャンルを決める
2. 台本（`02_...`）を読み、直したい言葉や場面を書き換える
3. `04_アニメーションの雰囲気.md` で見た目と声の方針を確認する
4. `03_制作の進め方.md` の順番で、絵・声・音楽・動画を作る

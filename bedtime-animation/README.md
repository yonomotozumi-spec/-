# 寝かしつけアニメーション 企画フォルダ

子どもが寝るときに見る、短いアニメーションを作るための企画資料です。

## ファイル一覧

| ファイル | 内容 |
|---|---|
| `01_ジャンル案.md` | 寝かしつけアニメの基本ルールと、ジャンル候補6案の比較・おすすめ |
| `02_台本_おつきさまのこぶね.md` | おすすめジャンルの完成台本（約6分30秒、18カット、歌詞つき） |
| `03_制作の進め方.md` | 台本を実際の動画にするまでの手順（プログラミング不要） |

## 進め方

1. `01_ジャンル案.md` を読んで、ジャンルを決める
2. 台本（`02_...`）を読み、直したい言葉や場面を書き換える
3. `03_制作の進め方.md` の順番で、絵・声・音楽・動画を作る

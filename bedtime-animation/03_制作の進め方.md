# 制作の進め方（プログラミング不要）

台本を動画にするまでの流れです。すべて「文章を入力して生成する」道具で進められます。

## 全体の流れ

```
台本 → ①キャラクター・背景の絵 → ②各カットの静止画 → ③静止画を動かす（動画化）
     → ④ナレーション音声 → ⑤BGM → ⑥動画編集でつなぐ → ⑦書き出し
```

## ① キャラクターと背景の絵を決める（画像生成）

最初に「ゆう」「こぶね」「ほしのこ」の見た目を1枚ずつ作り、それを基準にします。
見た目の方針と共通フレーズは `04_アニメーションの雰囲気.md` にまとめてあります。
どのカットでも同じ見た目になるよう、同じ説明文を使い回します。

**画像生成の指示文（例・主人公）**
> 絵本風、やわらかい色鉛筆のタッチ。3歳くらいの子ども「ゆう」。丸くてぽってりした体、頭が大きめ、水色のパジャマ、茶色いくまのぬいぐるみを抱えている。大きめの眠そうな目、ピンクのほっぺ。フェルトのようなふわふわした質感。背景は紺色の夜、パステルのアクセント、低彩度、穏やか。

**画像生成の指示文（例・舟）**
> 三日月の形をした小さな舟。やわらかいクリーム色に光っている。舟の先に、丸くてぽってりした小さな星の子（ピンクのほっぺ、眠そうな目）が座っている。絵本風、色鉛筆のタッチ、ふわふわした質感、紺色の夜空、穏やか。

**共通で必ず入れる言葉**
- 「絵本風」「やわらかい」「低彩度」「紺色の夜」
- 「眠そうな目」「ほほえみ」
- 入れてはいけない言葉：「明るい」「元気」「カラフル」「ダイナミック」

## ② 各カットの静止画を作る

台本の「映像」欄をそのまま指示文にします。19カット分を作ります。
旅先のあいだの「つなぎ（夜空を進む）」は1枚を使い回し、編集で空の色を少しずつ暗くします。
動物8匹は、それぞれ「目を開けている絵」と「目を閉じた絵」の2枚を作ると、動画化で「眠る」動きが出しやすくなります。

## ③ 静止画を動かす（画像→動画）

Kling などの「画像から動画」機能に静止画を入れ、動きだけを指示します。

**動きの指示文（例・カット10 くじら）**
> カメラは固定。くじらが水面でゆっくり上下に揺れる。波がゆるやかに動く。月の光が水面でかすかにきらめく。とてもゆっくり、穏やかに。

**動きの指示の共通ルール**
- 「カメラは固定」または「カメラはごくゆっくり横に動く」のどちらかにする
- 「とてもゆっくり」「穏やかに」を毎回入れる
- 1本5〜10秒で作り、足りない分は編集でゆっくり再生（0.5倍速など）にして伸ばす

## ④ ナレーションを作る（音声生成）

ElevenLabs などの読み上げで、台本の「ナレーション」欄を1カットずつ作ります。

- 声：低め、落ち着いた、やさしい女性または男性の声
- 速さ：通常の 0.8倍くらい
- 1文ごとに2〜3秒の無音を入れる（編集で後から入れてもよい）
- 親御さん自身の声を録音して使うのもおすすめです（子どもがいちばん安心する声です）

## ⑤ BGMを用意する

- オルゴール、ハープ、ハミングなどの子守歌風。歌詞なし。
- 1分間に60拍くらいのゆっくりしたテンポ。
- フリー音源サイトで「オルゴール 子守歌」などで探すか、音楽生成サービスで作る。
- 台本末尾の歌詞を使って歌入りを作る場合も、まずはハミング版から。

## ⑥ 動画編集でつなぐ

CapCut、iMovie、Canva などの編集アプリで、以下の順に重ねます。

1. ③で作った動画を台本のカット順に並べる
2. カットの切り替えは「ゆっくりフェード（1〜2秒）」に統一する
3. ④のナレーションを各カットの上に置く
4. ⑤のBGMを全体にうすく敷く（ナレーションの半分くらいの音量）
5. 最後の30秒は画面を徐々に黒くし、音も徐々に小さくする
6. 最後の5秒は真っ黒・無音

## ⑦ 書き出しと見せ方

- 画面サイズ：横長（16:9）。テレビやタブレットで見るため。
- 画質：1080p で十分。
- 再生時のコツ：
  - 画面の明るさを最低近くまで下げる
  - 「次の動画を自動再生」をオフにする
  - 寝室の照明を消してから再生する

## 最初の1本を作るときの目安

| 作業 | 回数・量 | 目安時間 |
|---|---|---|
| キャラ・背景の絵を決める | 3〜5枚（納得いくまで何度か） | 1〜2時間 |
| カットの静止画 | 約22枚（動物8匹×2＋部屋・空・月など） | 3〜4時間 |
| 動画化 | 約16本 | 2時間（生成待ち含む） |
| ナレーション | 19カット分 | 1時間 |
| 編集・書き出し | 1本 | 2〜3時間 |

まずは **カット1〜4（部屋から舟で飛び立つまで）の1分だけ** を試作して、
絵の雰囲気と声のテンポを確かめてから残りを作ると、やり直しが少なくて済みます。

# 制作の進め方（プログラミング不要）

台本を動画にするまでの流れです。すべて「文章を入力して生成する」道具で進められます。

## 全体の流れ

```
台本 → ①キャラクター・背景の絵 → ②各カットの静止画 → ③静止画を動かす（動画化）
     → ④ナレーション音声 → ⑤BGM → ⑥動画編集でつなぐ → ⑦書き出し
```

## ① キャラクターと背景の絵を決める（画像生成）

最初に「さく」「こぶね」「ほしのこ」の見た目を1枚ずつ作り、それを基準にします。
見た目の方針と共通フレーズは `04_アニメーションの雰囲気.md` にまとめてあります。
どのカットでも同じ見た目になるよう、同じ説明文を使い回します。

**画像生成の指示文（例・主人公）**
> 絵本風、やわらかい色鉛筆のタッチ。3歳くらいの子ども「さく」。丸くてぽってりした体、頭が大きめ、水色のパジャマ、茶色いくまのぬいぐるみを抱えている。大きめの眠そうな目、ピンクのほっぺ。フェルトのようなふわふわした質感。背景は紺色の夜、パステルのアクセント、低彩度、穏やか。

**画像生成の指示文（例・舟）**
> 三日月の形をした小さな舟。やわらかいクリーム色に光っている。舟の先に、丸くてぽってりした小さな星の子（ピンクのほっぺ、眠そうな目）が座っている。絵本風、色鉛筆のタッチ、ふわふわした質感、紺色の夜空、穏やか。

**共通で必ず入れる言葉**
- 「絵本風」「やわらかい」「低彩度」「紺色の夜」
- 「眠そうな目」「ほほえみ」
- 入れてはいけない言葉：「明るい」「元気」「カラフル」「ダイナミック」

**Kling で実際に試した設定（カット4・採用）**
- 道具：Kling の「文章から画像」（モデル kling-image-v3_0_omni）、16:9、2K、1枚。消費 2クレジット。
- 結果：`images/カット04_こぶねで夜空へ_v1.png`（採用）。
- 使った指示文（この文を土台に、場面ごとに「映像」欄の内容を差し替える）：

```
絵本風のやさしいイラスト、やわらかい色鉛筆のタッチ、フェルトのようなふわふわした質感。
夜、子ども部屋の窓から、三日月の形をした小さな舟がゆっくり夜空へ浮かび上がっていく場面。
舟はやわらかいクリーム色に光っている。
舟には3歳くらいの子ども「さく」が乗っている：丸くてぽってりした体、頭が大きめ、水色のパジャマ、
茶色いくまのぬいぐるみを抱えている、大きめの眠そうな半分閉じた目、ピンクの丸いほっぺ、小さな口でほほえんでいる。
舟の先には小さな星の子「ほしのこ」が座っている：丸くてぽってりした五角星の形、ピンクのほっぺ、眠そうな目、やさしく光っている。
背景は紺色とラベンダーの夜空、少しの星、遠くにやわらかい雲。
色はネイビー、ラベンダー、ミント、ピーチ、クリーム色のパステルで低彩度。
穏やかで静かな雰囲気、かわいい、子ども向け。太めのやわらかい線。文字なし。
```

## ② 各カットの静止画を作る

台本の「映像」欄をそのまま指示文にします。19カット分を作ります。
旅先のあいだの「つなぎ（夜空を進む）」は1枚を使い回し、編集で空の色を少しずつ暗くします。
動物8匹は、それぞれ「目を開けている絵」と「目を閉じた絵」の2枚を作ると、動画化で「眠る」動きが出しやすくなります。

## ③ 静止画を動かす（画像→動画）

Kling などの「画像から動画」機能に静止画を入れ、動きだけを指示します。

**動きの指示文（例・カット10 くじら）**
> カメラは固定。くじらが水面でゆっくり上下に揺れる。波がゆるやかに動く。月の光が水面でかすかにきらめく。とてもゆっくり、穏やかに。

**Kling で実際に試した設定（カット4）**
- 道具：Kling の「画像から動画」（モデル kling-video-v3_0_turbo）、5秒、1080p、1本。消費 50クレジット。
- 結果：`videos/カット04_こぶねで夜空へ_v1.mp4`（5秒・1916×1080・24fps）。
- 音声なしのモデルを選ぶ（ナレーションと効果音は別で作って編集で重ねるため）。
- 使った動きの指示文：

```
カメラは固定。とてもゆっくり、穏やかに。
三日月の舟が波のようにゆらゆらと小さく揺れながら、ごくわずかに上へ浮かび上がる。
子どもは眠ったまま、胸が呼吸でゆっくり上下する。星の子はやさしく光が明滅し、小さくまばたきする。
くまのぬいぐるみの耳がぴくっと動く。窓の外の星が静かにまたたき、雲がごくゆっくり流れる。カーテンがかすかに揺れる。
すべての動きは小さく、ゆっくり、ループするように。絵本風のフェルト質感を保つ。
急な動き、カメラの移動、新しい物体の登場はなし。
```

**動物のしぐさ5本（カット5〜9）も同じ設定で動画化済み（2026-10-13）**
- モデル kling-video-v3_0_turbo、5秒、1080p、1本ずつ。消費 50クレジット×5本＝250クレジット。
- 結果：`videos/カット05_ふくろうの木_v1.mp4`〜`videos/カット09_ペンギンの島_v1.mp4`（各5秒・1916×1080・24fps、音声なし）。
- 指示文は毎回「カメラは固定。とてもゆっくり、穏やかに。」で始め、動物のしぐさを1つだけ書き、
  末尾は「すべての動きは小さく、ゆっくり、穏やか。絵本風のフェルト質感を保つ。急な動き、カメラの移動、新しい物体の登場はなし。」で締める。

| カット | しぐさの指示（中心部分） |
|---|---|
| 5 ふくろう | 枝の上のふくろうが大きく「ふぁ〜」とあくびをして、まんまるの目がとろんと半分になり、最後にそっと閉じる。葉っぱが1枚ゆっくり落ちる。 |
| 6 うさぎ | 白いうさぎの立った耳が、片方ずつ「ぱたん」「ぱたん」とゆっくり倒れ、うさぎはそのまま丸くなって目を閉じる。草がかすかに揺れる。 |
| 7 ひつじ | 丸くなって眠るひつじたちの背中が、呼吸でゆっくり上下する。1匹だけが「ころん」とゆっくり寝返りをうつ。 |
| 8 ぞう | お母さんぞうが長い鼻で大きな葉っぱをそっと子ぞうにかけてあげ、子ぞうが目を閉じてほほえむ。川の水面がゆらり、ゆらりと静かに揺れる。 |
| 9 ペンギン | ペンギンたちがよちよちと少しだけ真ん中に寄り、ぎゅっと寄りそって1つの丸になり、目を閉じる。氷の島のまわりの波がゆらり、ゆらりと揺れる。 |

- 毎回「三日月の舟がゆらゆらと小さく揺れ、星の子がやさしく明滅する」も添えて、主人公側の動きをそろえている。
- 残り13場面（カット1〜3、10〜18、つなぎ）も同じ設定で動画化済み（2026-10-13、クレジット買い足し後。50×13＝650クレジット）。
  これで19場面すべてに5秒の動画がそろった → `videos/カット01…18_v1.mp4`、`videos/つなぎ_夜空を進む_v1.mp4`。
- 注意：Kling の絵の読み込み用リンクは24時間で切れる。作り直した絵（カット14 v2）は作り直し時の生成IDから取り直す必要があった。

**動きの指示の共通ルール**
- 「カメラは固定」または「カメラはごくゆっくり横に動く」のどちらかにする
- 「とてもゆっくり」「穏やかに」を毎回入れる
- 1本5〜10秒で作り、足りない分は編集でゆっくり再生（0.5倍速など）にして伸ばす

## ④ ナレーションを作る（音声生成）

声の方針は「落ち着いた大人の男性、ゆっくり、抑揚しっかり」です（詳細は `04_アニメーションの雰囲気.md`）。

ElevenLabs などの読み上げで、台本の「ナレーション」欄を1カットずつ作ります。

- 声：男性、低め、calm / warm / storyteller などの説明がある声
- 速さ：0.75〜0.8倍
- 安定性：中くらい、スタイルの強さ：中くらい（抑揚を残すため）
- 1文ごとに2秒の無音を入れる（編集で後から入れてもよい）
- まずカット5（ふくろう）の3文だけで試し、声を決めてから全体を作る
- お父さんの声を録音して使う方法もあります。生成した声と聞き比べて、子どもの反応で決めるのがおすすめです

動物の鳴き声は、フリー効果音サイトで「ふくろう 鳴き声」「ねこ 鳴き声 眠い」などを探すか、音声生成で擬音（「ほ〜…」）をそのまま読ませても作れます。
編集で音量をナレーションの3分の1に下げ、語尾をフェードアウトさせると「眠そう」になります。

## ⑤ BGMを用意する

- オルゴール、ハープ、ハミングなどの子守歌風。歌詞なし。
- 1分間に60拍くらいのゆっくりしたテンポ。
- フリー音源サイトで「オルゴール 子守歌」などで探すか、音楽生成サービスで作る。
- 台本末尾の歌詞を使って歌入りを作る場合も、まずはハミング版から。

**ElevenLabs（完全版）で実際に作った BGM（2026-10-13）**
- モデル eleven_music_v2_5、歌なし（instrumental）、90秒を2本（候補A・B）。消費 1,350クレジット×2。
  5分を直接作ると 7,500クレジット/本 と高いため、90秒を作って編集でくり返す方式にした。
- 使った指示文（英語の方が安定）：
  > Gentle music box lullaby, instrumental only, no vocals, no drums, no bass. A soft music-box / celesta melody with sparse harp and single warm piano notes, very slow tempo around 60 BPM, major key but subdued and dreamy. One short simple melody repeats calmly with tiny variations, no build-up, no climax, no sudden changes, constant quiet dynamics from start to end so it can loop seamlessly. Intimate, cozy, bedtime, sleepy, airy with soft reverb.
- 結果：候補Bを採用（2026-10-13）→ `bgm/BGM_オルゴール子守歌_90秒.mp3`。候補Aは `archive/bgm_候補A/`。
- ループ版：90秒を4回つなぎ（3秒ずつ重ねてフェード）、通し見本の長さ（4分48秒）に切り、最後の約60秒でフェードアウト。
  2本の音量がかなり違ったので、平均音量をそろえてから（ナレーションより約6dB小さい）重ねた。
  → `bgm/BGM_オルゴール子守歌_ループ4分48秒.mp3`（音量調整済み。編集ではこのファイルをそのまま重ねればよい）
- BGM入りの通し見本：`videos/通し見本_v2_BGM入り_720p.mp4`

## ⑤-2 効果音を用意する（2026-10-13 実施）

- ElevenLabs（完全版）の効果音生成（eleven_text_to_sound_v2）で、台本の「音」欄どおり9種を作成。1本5〜13クレジットと安い。
  ふくろう「ほ〜」、うさぎ「きゅぅ」、ひつじ「めぇ」、ぞうの鼻息、ペンギン「くぅ」、くじら「ぷおぉ」、こねこ「にゃぁ」、鈴「チリン」、遠くの時計の鐘。
- 指示文は英語で「a single soft, sleepy ○○ ... one ○○ only, quiet, gentle」のように、1回だけ・小さく・眠そうに、と書く。
- 生成直後は音量がばらばらなので、ピークを -12dB（鈴・時計は -16dB）にそろえた（ナレーションの半分くらい） → `sfx/`。
- 入れる位置は、各カットのナレーションの最初の間（「○○さん。」のあと）。秒数は `sfx/配置表.md`。
- 効果音＋BGM入りの通し見本：`videos/通し見本_v3_BGM効果音入り_720p.mp4`。

## ⑥ 動画編集でつなぐ

CapCut、iMovie、Canva などの編集アプリで、以下の順に重ねます。

1. ③で作った動画を台本のカット順に並べる
2. カットの切り替えは「ゆっくりフェード（1〜2秒）」に統一する
3. ④のナレーションを各カットの上に置く
4. ⑤のBGMを全体にうすく敷く（ナレーションの半分くらいの音量）
5. 最後の30秒は画面を徐々に黒くし、音も徐々に小さくする
6. 最後の5秒は真っ黒・無音

**通し見本（2026-10-13 作成）**

- 19枚の絵を台本順に並べ、各カットの絵をごくゆっくり寄せ（ズーム）、Haruma のナレーションを重ねたもの。
  動物の間には「つなぎ」の絵（4〜7秒）を挟み、最後は「おやすみ」のあと4秒の真っ黒・無音で終わる。
- まだ入っていないもの：Kling の動き（カット4〜9の動画）、動物の鳴き声の効果音、BGM。
  本番の編集では、この見本のカット4〜9の絵を `videos/` の動画に差し替え、BGM をうすく敷く。
- 作り方：編集アプリを使わず ffmpeg（無料の変換ツール）で自動生成。1カットの長さ＝「前に1.2秒の間＋ナレーション＋後ろに2.8秒の間」。

## ⑦ 書き出しと見せ方

- 画面サイズ：横長（16:9）。テレビやタブレットで見るため。
- 画質：1080p で十分。
- 再生時のコツ：
  - 画面の明るさを最低近くまで下げる
  - 「次の動画を自動再生」をオフにする
  - 寝室の照明を消してから再生する

## 最初の1本を作るときの目安

| 作業 | 回数・量 | 目安時間 |
|---|---|---|
| キャラ・背景の絵を決める | 3〜5枚（納得いくまで何度か） | 1〜2時間 |
| カットの静止画 | 約22枚（動物8匹×2＋部屋・空・月など） | 3〜4時間 |
| 動画化 | 約16本 | 2時間（生成待ち含む） |
| ナレーション | 19カット分 | 1時間 |
| 編集・書き出し | 1本 | 2〜3時間 |

まずは **カット1〜4（部屋から舟で飛び立つまで）の1分だけ** を試作して、
絵の雰囲気と声のテンポを確かめてから残りを作ると、やり直しが少なくて済みます。

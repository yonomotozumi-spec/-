# アニメーションの雰囲気ガイド（見た目・動き・音声）

「眠くなる」ことは守りつつ、子どもが「かわいい」「もう1回みたい」と思う見た目にするための方針です。
画像生成や動画生成の指示文、声の選び方は、ここに書いた言葉をそのまま使います。

---

## 1. 見た目（キャラクターデザイン）

### 基本の形
子どもが好む形は「丸くて、ぽってり、短い手足」です。

| 要素 | 方針 | 避けること |
|---|---|---|
| 体の形 | 丸・楕円を基本にしたぽってり体型。頭が大きめ（頭：体 = 1：1〜1：1.5） | 細長い、リアルな体型 |
| 目 | 大きめで、ふだんは **半分とろんとした目**。眠る直前に「まんまる → とろん → 閉じる」と変化 | 鋭い目、白目が多い目 |
| ほっぺ | 丸いピンクの赤み（必ず入れる。かわいさの決め手） | なし |
| 口 | 小さい「ω」や「・」。あくびのときだけ大きく開く | 歯を見せる |
| 線 | 太めで、やわらかい色鉛筆の線（黒ではなく濃い紺や茶） | 細い黒線 |
| 質感 | フェルト・ぬいぐるみ・やわらかい紙のような、ふわふわの質感 | つるつる、光沢 |

### 色（夜なのに、かわいい）
背景は紺や藍で統一しますが、キャラクターにはパステルのアクセントを入れます。

| 役割 | 色 |
|---|---|
| 背景（空・海） | ネイビー、藍、深いラベンダー |
| 光（月・舟・ほしのこ） | クリーム色、やわらかい金色 |
| キャラクターのアクセント | ラベンダー、ミント、ピーチ、ベビーブルー |
| ほっぺ | 淡いピンク |
| 使わない色 | 真っ白、原色の赤・黄・青、蛍光色 |

### 画像生成の共通フレーズ（毎回この言葉を入れる）
> 絵本風、やわらかい色鉛筆のタッチ、丸くてぽってりしたかわいいキャラクター、大きめの眠そうな目、ピンクのほっぺ、フェルトのようなふわふわした質感、紺色の夜、パステルのアクセント、低彩度、穏やか

### 画像生成で入れてはいけない言葉
「元気」「明るい」「カラフル」「かっこいい」「リアル」「ダイナミック」「3Dレンダリング」

## 2. 動き（子どもが喜ぶ、でも眠くなる動き）

子どもが好きな動きは「小さくて、かわいくて、オチがある」動きです。
激しい動きではなく、**1か所につき1つの小さなしぐさ** を見せます。

### 動きの3つの型
| 型 | 擬音 | 例 |
|---|---|---|
| ぽよん | 小さく1回はねる | ほしのこが喜ぶ、ふくろうが枝で揺れる |
| ふわ | ゆっくり浮く・落ちる | 舟の揺れ、葉っぱのおふとん、くじらの潮 |
| くるん | ゆっくり丸くなる・巻く | こねこのしっぽ、きりんの首、うさぎの耳 |

### 守ること
- 1つのしぐさは **3〜10秒** かけてゆっくり。
- 「速い動き」「跳びはねる」「走る」は全編で禁止。
- 同じ動き（舟の揺れ、ほしのこのぽよん）を毎回くり返す。子どもは「次もあれが来る」と分かると安心する。
- 眠りに近づくほど、動きは小さく・遅くする。旅の後半のぽよんは、前半より小さく。

### 動画生成の共通フレーズ
> カメラは固定、とてもゆっくり、穏やかに、やわらかい揺れ、小さな動き、ループするような動き

## 3. 音声（ナレーションの声）

### 決定した方針
**落ち着いた大人の男性の声。ゆっくり。抑揚はしっかりつける。**
「低くて穏やかなお父さんが、絵本を読み聞かせてくれる」イメージです。

| 項目 | 方針 |
|---|---|
| 声 | 大人の男性。低め。やわらかく、落ち着いている。若すぎず、年を取りすぎず（30〜50代の印象） |
| 速さ | ふつうの **0.7〜0.8倍**。1文読んだら2秒休む |
| 抑揚 | **しっかりつける**。「ふぁ〜」「ぱたん」「ぎゅっ」などの擬音は、絵本の読み聞かせのように表情豊かに |
| 音量 | 抑揚はつけるが **声は張らない**。大きくするのではなく、高低と間で表情をつける |
| 文末 | 必ず下げる。「おやすみ、〇〇さん」は、やさしく、ゆっくり、下げて終わる |
| 後半 | 旅が進むにつれて、抑揚は保ったまま音量だけ少しずつ小さく。最後の「おやすみ」はささやき |
| 息づかい | 少し息の混じった、近くで話しかけるような距離感 |

### 「抑揚あり」と「眠くなる」を両立するコツ
- 抑揚は **擬音と動物の名前** につけ、地の文（「〜に、〜がいました」）は平らに読む。
- 高くするのは「ぴんと立った耳」「ふわっ」など一瞬だけ。すぐ低く戻す。
- 「おやすみ、〇〇さん」だけは毎回まったく同じ調子で読む。ここが子どもの安心ポイント。

### 用意する方法

**① 音声生成サービス（ElevenLabs など）を使う**
声を選ぶときの条件：男性、「calm」「deep」「warm」「gentle」「narration」「storyteller」「bedtime」などの説明がある声。
設定の目安：
- 速さ：0.75〜0.8倍
- 安定性（Stability）：中くらい（高すぎると抑揚が消える。低すぎると声が揺れる）
- スタイルの強さ（Style）：中くらい（抑揚を出すため、ゼロにはしない）
- 読み上げる文：**漢字まじり・スペースなし** で入れる（`05_読み上げ用テキスト.md`）。ひらがなの分かち書きは単語ごとに切れて片言に聞こえる。擬音は「ふぁ〜」「ぱたん」のように台本どおり。
- まず **カット5（ふくろう）の3文だけ** で試し、声・速さ・抑揚を確かめてから全体を作る。

**採用した声（決定）**
`samples/ナレーション見本_カット5_ふくろう.mp3` が採用版の見本です。全カットはこの声・この設定で作ります。

**ElevenLabs で実際に試した設定（カット5のサンプル）**
- 声：Sumiku - Warm Expressive JP Narrator（低めで落ち着いた中年男性、朗読向け）
- モデル：eleven_v3（[ ] で囲んだ演出指示が使えるモデル）
- 指示文の書き方（文の前に演出を英語で入れ、間は「…」で表す）：

```
[gentle, slow bedtime storytelling, soft and warm] おおきな きに、ふくろうさん。 …
[yawning softly] ふぁ〜…。 おおきな あくびです。 …
[whispering gently, slowly] おやすみ、ふくろうさん。
```

- 1回の生成で4通りの読み方ができるので、いちばん落ち着いているものを選ぶ。
- ほかの候補の声：Shintarou-Explainer voice（40代・低くやわらか）、Haruma - Deep, Calm Japanese Male（さらに低音）、ZenShin-Clear & Calm Narrator（中年・落ち着き・朗読向け）。

**② 親御さん（お父さん）自身の声を録音する**
方針が「大人の男性の落ち着いた声」なので、お父さんの声があれば最も自然です。
スマホのボイスメモで、暗い部屋で、ふだんの絵本の読み聞かせと同じ調子で読みます。
生成した声と比べて、子どもの反応がよい方を採用するのもよい方法です。

### 動物の鳴き声
**入れる。ただし「軽い効果音」として。**

| ルール | 内容 |
|---|---|
| 回数 | 1匹につき **1回だけ** |
| 調子 | 眠そうに、小さく、語尾を伸ばして下げる（「ほ〜…」「めぇ〜…」） |
| タイミング | 動物が登場した直後、ナレーションが始まる前 |
| 音量 | ナレーションの **3分の1** くらい。「聞こえたかな？」程度 |
| 避けること | 元気な鳴き声、くり返し、2匹以上が同時に鳴く |

各動物の音は台本（`02_...`）の各カットに書いてあります。

## 4. 音楽と効果音

### BGM
| 項目 | 方針 |
|---|---|
| 楽器 | オルゴール、ハープ、ピアノの単音、ハミング |
| テンポ | 1分間に **60拍**（落ち着いた心臓の鼓動と同じ） |
| 曲の作り | 同じメロディを何度もくり返す。盛り上がる部分を作らない |
| 音量 | ナレーションの半分くらい。最後の1分で少しずつ消す |
| 調 | 長調（明るすぎない）。短調は悲しく聞こえることがある |

### 効果音（入れてよいもの）
| 場面 | 音 | 大きさ |
|---|---|---|
| 舟が現れる・消える | 鈴が1回「チリン」 | 小さく |
| 海 | 波の音「ざぁ…ざぁ…」6秒で1往復 | ごく小さく |
| 町 | 遠くの時計の鐘が1回 | ごく小さく |
| 動物の登場 | 眠そうな鳴き声を1回（台本参照） | ナレーションの3分の1 |
| 動物が眠る | 寝息「すぅ…すぅ…」 | ごく小さく |
| 風 | 「さぁ…」 | ほとんど聞こえないくらい |

### 効果音（入れないもの）
ドアの音、足音、水しぶき、元気な鳴き声・くり返す鳴き声、拍手、笑い声、「ピコン」などの電子音

## 5. 子どもが「もう1回」と言いたくなる工夫

眠気を妨げずに、子どもの好きな要素を入れる方法です。

- **決まり文句**：「おやすみ、〇〇さん」を毎回同じ言い方で。子どもが小さな声で一緒に言えるようになる。言うなら「ささやきで」と最初に親が教えてあげる。
- **マスコット**：「ほしのこ」をしゃべらない小さな相棒として毎回出す。シリーズ化したときも共通で登場させる。
- **数える**：ひつじを「ひとつ、ふたつ、みっつ」まで数える。全部は数えない（数え終わると目が覚める）。
- **おやすみサイン**：ゆうが動物に「手を胸にあてて、ぺこり」とする小さなしぐさを毎回入れる。子どもが寝る前にまねできる儀式になる。
- **探しもの（ごく小さく）**：各場面に「ほしのこ」の落とした小さな星を1つだけ隠す。見つけても声を出さなくていいよ、と最初に伝える。興奮しやすい子には入れない。

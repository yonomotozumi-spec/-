| 項目 | ファイル |

| 動画 | `videos/完成版_v2_1080p.mp4`（約4分47秒・64MB） |
| サムネイル（おすすめ） | `youtube/サムネ案B_ふくろう.jpg`（1280×720） |
| 字幕 | `youtube/寝かしつけアニメ_おつきさまのこぶね.ja.srt` |
| サムネイル（ほかの案） | `youtube/サムネ案A_お月さま.jpg`、`youtube/サムネ案C_くじら.jpg` |

サムネイルを自分で設定するには、YouTube アカウントの電話番号確認（本人確認）が先に必要です。

## タイトル（コピーして使う・SEO対策済み）

```
【寝かしつけ】眠くなる絵本アニメ「おつきさまのこぶね」赤ちゃん・幼児向け｜どうぶつたちに おやすみ
```

- いちばん検索される「寝かしつけ」を先頭に置いた（スマホでは先頭の約40文字しか表示されないため）。
- 「眠くなる」「絵本アニメ」「赤ちゃん」「幼児」など、親が検索しそうな言葉を自然に入れた。
- 作品名は「」でくくって、言葉の区切りをはっきりさせた。

## タグ（コピーして使う）

タグは今は補助的な扱いなので、表記ゆれ（ひらがな・漢字）を中心に入れています。

```
寝かしつけ, ねかしつけ, 寝かしつけ動画, 寝かしつけアニメ, 眠くなる動画, 赤ちゃん 寝る, 幼児 寝る, 絵本アニメ, 読み聞かせ, おやすみ, 子守歌, オルゴール, 睡眠導入, 動物 アニメ, おつきさまのこぶね
```

## 字幕ファイル（SEOに効く）

- `youtube/寝かしつけアニメ_おつきさまのこぶね.ja.srt`（ナレーションの字幕・65行、時間合わせ済み）
- 字幕の文字も検索の対象になるため、アップロードしておくと見つけてもらいやすくなる。
- 設定場所：YouTube Studio →「字幕」→ 言語「日本語」→「ファイルをアップロード」→「タイミングあり」を選んで srt を選ぶ。
- 字幕は初期状態では表示されない（視聴者が字幕ボタンを押したときだけ出る）ので、画面の邪魔にはならない。

## そのほかの SEO・見てもらう工夫

- **ファイル名**：アップロード前に動画ファイルの名前を `寝かしつけアニメ_おつきさまのこぶね.mp4` に変えておく。
- **再生リスト**：「寝かしつけ絵本アニメ」という再生リストを作って入れる。次の作品を作ったら同じリストに追加する。
- **公開の時間帯**：寝かしつけ動画は夕方〜夜（19〜21時ごろ）に探されやすいので、その時間に「公開」に切り替えるか予約公開にする。
- **長い版**：寝かしつけ動画は30分〜1時間の長い版がよく見られる傾向がある。今の動画をくり返した「30分版」「1時間版」を別に作ると、検索にかかる入口が増える（追加のクレジット不要で作れる）。
- 「子ども向け」に設定すると、コメント・終了画面・カードが使えなくなる。これは仕様なので気にしなくてよい。

## YouTube Studio での設定

| 設定 | 選ぶもの | 理由 |
|---|---|---|
| 視聴者 | **はい、子ども向けです** | 子ども向けの動画は法律上この設定が必須。コメント欄などは自動でオフになる |
| 公開範囲 | まず **限定公開** → 確認後に **公開** | 自分のスマホやテレビで一度見てから公開するため |
| カテゴリ | 映画とアニメ | |
| 動画の言語 | 日本語 | |
| 改変・合成コンテンツの開示 | いいえ（通常は不要） | 現実の人や出来事と見間違える映像ではないため |
| 年齢制限 | なし | |

## アップロードの手順

1. パソコンで YouTube Studio（studio.youtube.com）を開き、右上の「作成」→「動画をアップロード」
2. `完成版_v2_1080p.mp4` を選ぶ
3. 「詳細」でタイトル・説明文を貼り付け、サムネイルに `サムネ案B_ふくろう.jpg` を設定、再生リストを選ぶ
4. 「視聴者」で「はい、子ども向けです」を選ぶ
5. 「その他のオプション」でタグを貼り付け、カテゴリと言語を設定
6. 「字幕」で srt ファイルをアップロード
7. 「公開設定」で「限定公開」にして保存 → 自分で見て確認 → 問題なければ「公開」に変更

## 公開前に確認しておくこと（権利まわり）

- **Kling**：有料プラン（Standard）で作った映像なので、商用利用を含めて使える想定。最新の利用規約を一度確認する。
- **ElevenLabs**：ナレーションの多くは**無料プランの期間に作った音声**。無料プランで作った音声は、商用利用ができない・クレジット表記が必要、という条件だった時期がある。
  - 収益化しないなら、説明文のクレジット表記（上の「制作」欄）で足りる可能性が高い。
  - **収益化する場合**は、有料プランの今、ナレーション19本を同じ文で作り直しておくと安心（約1,500クレジット）。
  - BGM と効果音は有料プランに切り替えたあとに作ったもの。
- 規約は変わることがあるので、公開前に各サービスの最新の利用規約を確認してください。

## タイトル（コピーして使う・SEO対策済み）

```

```

- いちばん検索される「寝かしつけ」を先頭に置いた（スマホでは先頭の約40文字しか表示されないため）。

## 字幕ファイル（SEOに効く）

- `youtube/寝かしつけアニメ_おつきさまのこぶね.ja.srt`（ナレーションの字幕・65行、時間合わせ済み）
- 字幕の文字も検索の対象になるため、アップロードしておくと見つけてもらいやすくなる。
- 設定場所：YouTube Studio →「字幕」→ 言語「日本語」→「ファイルをアップロード」→「タイミングあり」を選んで srt を選ぶ。
- 字幕は初期状態では表示されない（視聴者が字幕ボタンを押したときだけ出る）ので、画面の邪魔にはならない。

## そのほかの SEO・見てもらう工夫

- **ファイル名**：アップロード前に動画ファイルの名前を `寝かしつけアニメ_おつきさまのこぶね.mp4` に変えておく。
- **再生リスト**：「寝かしつけ絵本アニメ」という再生リストを作って入れる。次の作品を作ったら同じリストに追加する。
- **公開の時間帯**：寝かしつけ動画は夕方〜夜（19〜21時ごろ）に探されやすいので、その時間に「公開」に切り替えるか予約公開にする。
- **長い版**：寝かしつけ動画は30分〜1時間の長い版がよく見られる傾向がある。ただし、同じ動画をくり返しただけの版をいくつも出すと「量産型コンテンツ」と判断されるおそれがある。作るなら1本だけにして、BGM だけの静かな延長部分を足すなど中身を変える。
- 「子ども向け」に設定すると、コメント・終了画面・カードが使えなくなる。これは仕様なので気にしなくてよい。

## アップロードの手順

1. パソコンで YouTube Studio（studio.youtube.com）を開き、右上の「作成」→「動画をアップロード」
2. `完成版_v2_1080p.mp4` を選ぶ
3. 「詳細」でタイトル・説明文を貼り付け、サムネイルに `サムネ案B_ふくろう.jpg` を設定、再生リストを選ぶ
4. 「視聴者」で「はい、子ども向けです」を選ぶ
5. 「その他のオプション」でタグを貼り付け、カテゴリと言語を設定
6. 「字幕」で srt ファイルをアップロード
7. 「公開設定」で「限定公開」にして保存 → 自分で見て確認 → 問題なければ「公開」に変更

## 公開前に確認しておくこと（権利まわり・2026-10-14 確認）

各サービスの公式ページ（ヘルプ・規約・プラン表）で確認した内容です。規約は変わるので、収益化の申請前にもう一度見てください。

### Kling（映像・絵）→ 問題なし

- 無料の Basic プランは商用利用不可。Standard 以上の有料プランは商用利用可。
- このアカウントは制作開始時（2026-10-13）から **Standard プラン**。映像19本と絵はすべて Standard の期間に作ったので、収益化に使える。

### ElevenLabs（ナレーション・BGM・効果音）→ ナレーション10本だけ作り直しが必要

- 規約：無料プランは「商用利用不可・公開時はクレジット表記が必要」。有料プランの期間に作ったものは商用利用可。
- **ヘルプページに「有料プランの期間外（前でも後でも）に作ったものは商用利用できない」とある。あとから課金しても、無料の期間に作った音声は商用OKにならない。**
- 課金したのは 2026-10-13 10:30 ごろ。最終版の素材を作った時刻で分けると次のとおり。

| 素材 | 作った時期 | 収益化 |
|---|---|---|
| ナレーション カット1・3・4・13・14・15・16・17・つなぎ（9本） | 課金後 | 使える |
| ナレーション カット2・5・6・7・8・9・10・11・12・18（10本） | 課金前（無料プラン） | **作り直しが必要** |
| BGM（オルゴール子守歌 B案） | 課金後 | 使える |
| 効果音9種 | 課金後 | 使える |

- 作り直す10本には「おふね」が入っていないので、抑揚の調整は不要。同じ声・同じ指示・同じ文で生成し直すだけ。
- 費用の目安：1本ずつなら約800クレジット、4通りずつ作って選ぶなら約3,000クレジット。
- **今のまま公開する場合（収益化しない）も条件がある**：無料プランで作った音声を使うときは、動画の**タイトル**に「elevenlabs.io」か「11.ai」を入れる決まり（説明文の表記だけでは足りない）。そのときのタイトルは次のとおり。

```
【寝かしつけ】眠くなる絵本アニメ「おつきさまのこぶね」赤ちゃん・幼児向け｜どうぶつたちに おやすみ｜11.ai
```

- **おすすめ**：公開前に10本を作り直す。作り直せば、タイトルの表記は不要になり、あとで収益化するときもそのまま使える。

### YouTube（収益化の条件）

- **収益化の申請条件**：チャンネル登録者1,000人と、直近12か月の総再生時間4,000時間など。申請できるようになるまでは、上の作り直しは急がなくてよい。
- **量産型コンテンツ**：AI で作った動画でも、独自のキャラクターや物語があれば収益化できる。テンプレートで少しずつ変えただけの動画を大量に出すと、収益化の対象外になる。この作品はオリジナルの物語なので問題ない。
- **子ども向けの品質**：「子ども向け」の動画は、子ども・家族向けの品質の基準で判断される。キーワードの詰め込みや、誤解を招くタイトル・サムネは避ける（今の案は問題ない）。
- **広告の単価**：「子ども向け」に設定するとパーソナライズド広告が出ないので、一般の動画より収益は低めになる。
- **AI の開示**：開示が必要なのは「本物と見間違える」内容（実在の人物・出来事など）。絵本調のアニメは対象外なので「いいえ」でよい。

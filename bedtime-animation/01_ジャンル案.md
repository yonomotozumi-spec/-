# 子ども向け「寝かしつけアニメーション」ジャンル案

## 企画の前提（共通ルール）

寝かしつけ用アニメは、ふつうのアニメと「逆」の作り方をします。
盛り上げず、ゆっくり落ち着かせて、最後は画面が暗くなって終わります。

| 項目 | 方針 |
|---|---|
| 対象年齢 | 2〜6歳（親が一緒に見る前提） |
| 長さ | 5〜8分（短すぎると寝つく前に終わり、長すぎると目が冴える） |
| テンポ | 1カット 8〜15秒。カット数は少なめ（全体で15〜25カット） |
| 色 | 紺・藍・紫・琥珀色などの低彩度。白や原色の強い光は使わない |
| 動き | ゆっくり揺れる・ふわっと浮く・ゆっくりまばたき。走る・跳ねるは禁止 |
| 音 | ナレーションは低め・ゆっくり。BGMはオルゴールやハミング。効果音は小さく |
| 構成 | 「おやすみ」を繰り返す → 画面が少しずつ暗くなる → 無音で終わる |
| 禁止事項 | 驚かせる展開、大きな音、点滅、クイズや呼びかけ（目が覚めてしまう） |

---

## ジャンル候補（6案）

### A. おつきさまのこぶね 【おすすめ】
**内容**：夜、小さな子が三日月のこぶねに乗って夜空を静かに進み、眠っている動物や町に「おやすみ」を言ってまわる。最後は自分のベッドに戻って眠る。

- よい点：繰り返し構造（おやすみ→次の場所→おやすみ）が眠気を誘う。背景を変えるだけなので絵の種類が少なくて済む。
- 注意点：旅の「途中」で盛り上げたくなるが、我慢して一定のテンポを守る。
- 制作しやすさ：★★★★★（背景数枚＋主人公1体＋動物数体）

### B. もりのどうぶつたち、おやすみのじゅんばん
**内容**：森の動物が1匹ずつ順番に寝ていく。「うさぎさんが ねました。つぎは…」と積み重ねていく。

- よい点：数の積み重ねが子どもに分かりやすい。「次は誰？」で安心感が続く。
- 注意点：動物ごとに絵が必要で、キャラ数が多い。
- 制作しやすさ：★★★☆☆

### C. ぬいぐるみたちの、しずかなおへや
**内容**：子どもが寝た後、ぬいぐるみたちがそっと部屋を片づけ、カーテンを閉め、電気を消して自分たちも眠る。

- よい点：自分の部屋と重なり、親近感が強い。「おもちゃも寝る」が片づけの習慣づけにもなる。
- 注意点：「夜に動くおもちゃ」を怖いと感じる子もいる。表情をやさしく保つ必要がある。
- 制作しやすさ：★★★★☆

### D. おやすみのうた（ララバイ型）
**内容**：物語はほぼなし。やさしい子守歌に合わせて、雲・星・波などの抽象的な映像がゆっくり流れる。

- よい点：最も眠りやすい。何度見ても飽きない（物語の「先」が気にならない）。
- 注意点：オリジナル曲が必要。歌がないと単調で親の方が退屈に感じやすい。
- 制作しやすさ：★★★★☆（絵は簡単だが音楽が要る）

### E. からだが ねむっていくよ（リラックス誘導型）
**内容**：「あしのゆびが ねむります。つぎは あし…」と体の端から順番に力を抜かせていくナレーション主体の作品。

- よい点：実際の入眠法（漸進的筋弛緩法）をもとにしており、効果が出やすい。
- 注意点：2〜3歳には少し抽象的。絵をどう付けるか工夫が要る（光が体を順に包む等）。
- 制作しやすさ：★★★☆☆

### F. よるのでんしゃ、ほしのえき
**内容**：ゆっくり走る夜行列車に乗って、ひとつずつ星の駅に止まる。駅ごとに乗客が降りて眠る。最後は「ゆめのえき」に到着。

- よい点：乗り物好きの子に強い。一定のリズム（ガタン、ゴトン）が入眠を助ける。
- 注意点：「電車」で興奮する子には逆効果の場合がある。
- 制作しやすさ：★★★★☆

## おすすめ

**第1候補：A「おつきさまのこぶね」**
眠りやすさと制作しやすさの両方が高く、最初の1本に向いています。
台本は `02_台本_おつきさまのこぶね.md` に用意しました。

**第2候補：F「よるのでんしゃ」**
A を作って手順に慣れたら、同じ構造（乗り物で場所を巡る）で2本目として作れます。
A の台本の「こぶね」を「でんしゃ」に、「空の上の景色」を「駅」に置き換えるだけで流用できます。

## シリーズ化のアイデア

A の形式が決まれば、乗り物や巡る場所を変えるだけで続編を作れます。

- おつきさまのこぶね（空の旅）
- くじらのせなか（海の旅）
- ほたるのあかり（森の旅）
- ゆきのそり（冬の旅）

# 不動産 適正価値 診断アプリ

物件情報を入力すると、不動産鑑定で用いられる **3つの評価手法**（取引事例比較法・収益還元法・原価法）から
**推定適正価値** を算出し、検討中の価格が「割安 / 適正 / 割高」かを判定するWebアプリです。

**住所（都道府県・市区町村）から、国土交通省「不動産情報ライブラリ」の実際の取引データを取得し、
相場単価を自動入力**できます（C案フル構成）。

---

## 2つの使い方

### ① オフラインで手入力（サーバー不要）
`index.html` をブラウザで開くだけで動きます。相場単価は自分で入力します。
デプロイもAPIキーも不要です。

### ② 住所から相場を自動取得（要デプロイ・APIキー）
中継サーバー（`api/reinfolib.js`）を介して国交省データを取得し、相場単価を自動入力します。
以下の「セットアップ」を行うと使えるようになります。

---

## セットアップ（自動取得を使う場合）

### 1. APIキーを取得する（無料）
[不動産情報ライブラリ](https://www.reinfolib.mlit.go.jp/) の「API機能」からAPIキーを申請します。

> ⚠️ **APIキーはコードに書かず、必ずデプロイ先の「環境変数」に設定してください。**
> このリポジトリのコードにキーは一切含まれていません。

### 2. デプロイする（Vercel の例）

```bash
# Vercel CLI を使う場合
npm i -g vercel
vercel                       # 初回デプロイ（プロジェクト作成）
vercel env add REINFOLIB_API_KEY   # 取得したAPIキーを設定
vercel --prod                # 本番デプロイ
```

- GitHub連携でVercelにインポートしてもOKです。その場合は Vercel の
  **Project → Settings → Environment Variables** に `REINFOLIB_API_KEY` を追加してください。
- `index.html` はルート（`/`）で配信され、`api/reinfolib.js` は `/api/reinfolib` として動きます。

### 3. 使う
デプロイ後のURL（例 `https://your-app.vercel.app`）を開き、
「住所から相場を自動取得」で都道府県・市区町村を選んで **「このエリアの相場を取得」** を押します。

> ローカルの `index.html` から使いたい場合は、アプリ内の「データ取得の接続設定」に
> デプロイ済みの絶対URL（例 `https://your-app.vercel.app/api/reinfolib`）を入力してください。

## 評価手法

| 手法 | 計算式 | 主な入力 |
| --- | --- | --- |
| **取引事例比較法** | 相場単価 × 面積 × 補正（築年数・駅距離） | 相場単価・面積・築年数・徒歩分 |
| **収益還元法** | NOI（賃料×12×(1−空室経費率)） ÷ 還元利回り | 月額賃料・利回り・経費率 |
| **原価法** | 土地価格 ＋ 建物再調達原価 × 残存率 | 土地単価・土地面積・面積・構造 |

物件種別ごとの標準的な加重で合成します（例：マンションは比較法 55% / 収益 30% / 原価 15%）。
入力が足りない手法は自動的に除外されます。

## 土地価格のクロスチェック（公示地価・路線価・固評）

土地単価を、複数の公的指標から**実勢換算して横並びで確認**できます。指標間の乖離が大きい場合は警告します。

| 指標 | 入力方法 | 実勢への換算 |
| --- | --- | --- |
| **公示地価** | 住所→「取得」ボタンで自動（国交省API＋国土地理院ジオコーディング） | × 市場係数 |
| **路線価** | [国税庁 路線価図](https://www.rosenka.nta.go.jp/) を見て手入力（千円/㎡） | ÷10 ÷0.8 × 市場係数 |
| **固定資産税評価額** | 課税明細から手入力（万円/㎡） | ÷0.7 × 市場係数 |
| **取引相場** | 「相場を自動取得」の土地成約から | そのまま |

- 換算根拠：路線価は公示地価の約80%、固評は約70%。**市場係数**は「実勢÷公示」で、人気エリアは 1.1〜1.3 程度に調整します。
- 採用値（各指標の中央値）が原価法の土地単価に反映されます。
- ⚠️ 路線価は国税庁に公式APIが無いため**手入力**です。公示地価の自動取得はGISタイル方式で、近傍に地点が無い場合は手入力にフォールバックします。

## 判定基準

`検討価格 ÷ 推定適正価値` の比率で判定します。

- **〜0.90**：割安 / **0.90〜1.10**：適正 / **1.10〜1.25**：やや割高 / **1.25〜**：割高

## 構成

```
index.html          フロントエンド（単一ファイル・UI＋計算ロジック）
api/reinfolib.js    中継サーバーレス関数（APIキーを保持・CORS対応・取引データ集計）
package.json        Node ランタイム宣言
```

### 中継APIの仕様（`/api/reinfolib`）
- `?resource=cities&area=13` … 都道府県内の市区町村一覧
- `?resource=price&area=13&city=13103&year=2023` … 取引価格を種別ごとに集計し、㎡単価（万円/㎡）の中央値を返す
- `?resource=landprice&lat=35.68&lon=139.76` … 緯度経度近傍の公示地価・地価調査の中央値（万円/㎡）を返す

いずれも環境変数 `REINFOLIB_API_KEY` を用いて国交省APIを呼び出します。
公示地価の取得では、フロント側で[国土地理院ジオコーディングAPI](https://msearch.gsi.go.jp/)（無料・キー不要）を使い住所→緯度経度に変換しています。

## データについての注意

- 国交省データは **四半期ごと・市区町村/地区単位の取引集計** です。ピンポイントの住所査定ではなく、
  「そのエリアの直近成約から相場水準を割り出す」ものです。
- 算出結果は入力値と一般的な評価モデルに基づく **簡易的な推定** です。
  実際の市場価格・担保評価・鑑定評価額とは異なります。
- 不動産情報ライブラリ API の仕様（エンドポイント・項目名）は変更される可能性があります。
  変わった場合は `api/reinfolib.js` 冒頭の定数（`EP_PRICE` / `EP_CITIES` / 項目名）を調整してください。
- 重要な意思決定の際は、不動産会社の査定や不動産鑑定士による正式な評価をご利用ください。

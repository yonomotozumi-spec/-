# 運用目標 (2026-08-26 改定 / 四半期見直し制)

## 前提

- 運用資金: **150万円**（余剰資金・全損許容の範囲）
- 根拠: 実データバックテスト 2023-09〜2026-08 で年率+11.8% / ボラ15.4% / Sharpe 0.76
- スタイル: 日足スイングトレード（現物 → エッジ実証後に信用2倍まで）

## 目標ラダー（強気・段階レバレッジ方式）

| 時点 | 目標 | 達成確率 (試算) | 条件 |
|---|---|---|---|
| 2026年末 | 165万円 (+10%) | 約27% | 現物・プランA |
| 2027年末 | 220万円 (+47%) | 約28% | 実測Sharpe ≥ 0.8 で信用2倍へ移行 |
| 2028年末 | 300万円 (2.0倍) | 約22% | 信用2倍を継続できた場合 |

- 試算: `analysis/target_plan.py`（10万パスのモンテカルロ）
- 中央値シナリオ: 2026年末 156万 → 2027年末 181万 → 2028年末 210万

## ガードレール（下振れ管理）

- **撤退・全面見直しライン: 資産120万円 (-20%)** — 到達時は新規買い停止、戦略再評価
- 信用2倍移行後は -30〜40% のドローダウンを高確率で経験する前提を置く
- 元本割れ確率 (2028年末時点試算): 現物のみ 16% / 信用2倍移行後 24%

## 四半期見直しルール

各四半期末（3・6・9・12月）に実測パフォーマンスを評価し、目標を改定する:

- 実測Sharpe が改善 → 目標を上方修正
- 実測Sharpe < 0.5 が2四半期連続 → 戦略見直し・目標を下方修正
- レバレッジ許可の判定: 直近3ヶ月の実測Sharpe ≥ 0.8 かつ最大DD > -15% で信用1.5倍、
  ≥ 1.2 で2倍まで

## エッジ改善ロードマップ（確率を上げる手段）

1. 候補プール拡大 50 → 118銘柄（2026-08-26 実施）
2. 単元株モードの並行計測（`config/planLive.yaml`、kabuステーションAPI実弾を想定）
3. 出口ルールの改定：固定利確+20% → トレーリング利確-12%（2026-09-02 実施、下記）
4. 米国株の追加（フェーズ2、多通貨対応の実装後）
5. 執行改善・戦略多様化（決算モメンタム、セクターローテーション等）

### 出口ルール改定の根拠（2026-09-02）

`analysis/exit_sweep.py` で同一データ・同一シグナルのまま出口だけを差し替えて比較
（2023-09-01以降・5銘柄・50万円）。固定利確は「損切り幅の広さ」と非対称で、伸びる
銘柄を機械的に手放すため右裾を失っていた。

| 出口ルール | 通算 | Sharpe | 最大DD |
|---|---|---|---|
| 固定利確 +20%（旧設定） | +42.0% | 0.84 | -20.2% |
| 利確なし | +41.9% | 0.72 | -21.7% |
| **トレーリング -12%（採用）** | **+54.2%** | **1.04** | -19.7% |
| トレーリング -15% | +54.6% | 1.01 | -19.9% |

-15%は通算リターンがわずかに上回るが、リスク調整後（Sharpe）とDDで-12%が優位。
`planB.yaml` のみトレンド追随を優先する設計のため -15% を採用。

**次の見直し:** 2026年12月末の四半期レビューで、実測の平均保有日数・利確1件あたりの
利益率を確認し、トレーリング幅を再調整する。

### 【実施済 2026-09-11】単元株トラックの是正3点

1株トラックが15営業日に到達したため、予約していた変更を適用した。

| 項目 | 変更前 | 変更後 |
|---|---|---|
| 単元コスト上限 (planLive) | 37.5万円 (自動既定) | **15万円** (明示) |
| 1単元への切り上げ | なし | **目標が1単元の50%以上なら1単元取得** (`min_lot_fill_ratio`) |
| 損切り後のクールダウン | なし | **5営業日** (`stop_cooldown_days`) |

**効果 (適用直後の同日サイクル):**

| | 適用前 | 適用後 |
|---|---|---|
| 投資比率 | 44.9% | **93.2%** |
| 現金 | 810,513円 | **100,815円** |
| 保有銘柄 | 3 | **7** |

ユニバースを選び直し、9434/5401/9432/4188/4005/7261/5020/4755 を採用。
旧ユニバースの 8309.T・2801.T は単元コスト超過で対象外になったが、保有分は
売り判定のみ継続する (`resolve_universe` が保有銘柄をデータ取得に含める)。

**注意:** 単元株トラックの実測は 2026-09-11 で性質が変わった。以降のSharpe評価は
**2026-09-11 を起点**として数え直すこと。それ以前の記録は現金41%滞留下のもので
比較対象にならない。

### 判定履歴

**2026-09-11 (1株トラック15営業日):**
実測Sharpe **-1.08** / Sortino -1.45 / 最大DD -4.62% / 通算 -1.15%。
判定基準 (Sharpe >= 0.8 で信用1.5倍) に**届かず → 現物プランA継続、レバレッジ不可**。
サンプル15日は依然として短く、この数字は戦略の優劣を確定するものではない。
次回判定は2026年12月末の四半期レビュー。
